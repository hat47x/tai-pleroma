# SCN-002 複数拠点の設備更新優先度（合成）

3つの拠点、更新期限、故障、予算上限、承認という条件の下で、設備更新の優先順位を決める合成シナリオです。

**すべて架空の文書です。** 実在の施設・契約・予算ではありません。

## 入力

- `mmi/observations.csv`: 拠点・設備・期限・故障・予算の観測
- `mmi/guide.md`: MMIの読み取りガイド
- `tei/`: `Site` / `Asset` / `Budget` / `Priority`型

## 期待する成果

- 期限切れ・故障・予算制約を分けて保持する。
- 予算上限を超える案を確定しない。
- 承認者・契約・実費が未確認のままなら、未決として残す。

## 境界

- 合成データです。実在の資産・契約・予算ではありません。
- 優先度の意味・安全判断・発注は未検証です。
- 公開gateはblockedのままです。
