# SCN-003 補助金申請の一次審査（合成）

3件の申請、収入要件の食い違い、事業費上限、利益相反、採択枠を扱う合成シナリオです。

**すべて架空の申請・団体・予算です。** 実在の制度・団体ではありません。

## 入力

- `mmi/observations.csv`: 申請・要件・上限・利益相反・採択枠
- `tei/`: `Applicant` / `Criterion` / `Conflict` / `Score`型

## 期待する成果

- 収入要件の食い違いを解消せず、確認待ちとして保持する。
- 事業費上限を超える申請を採択しない。
- 利益相反がある申請を通常審査から外す。
- 採択枠2件を超えない。

## 境界

- 合成データです。実在の制度・申請・審査ではありません。
- 採択・不採択の確定判断ではありません。
- 公開gateはblockedのままです。
