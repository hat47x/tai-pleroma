# SCN-001 合成文書バリエーション

同じ「予約案内」でも、総則・例外・版・適用範囲の構成が異なる複数の合成入力を用意し、MMI/TEIの参照実装が入力差を扱えるかを確認します。

**すべて架空の文書です。** 実在の施設・規程・権限ではありません。

| 変種 | 構成 | 期待する確認 |
| --- | --- | --- |
| B | 本館と別館で予約条件が異なる | 適用範囲ごとの条件差を保持できるか |
| C | 全館予約制だが、旧掲示が予約不要としている | 版と旧掲示の差を保持できるか |

各変種は次を持ちます。

- `observations.csv`: MMI用の観測行
- `guide.md`: MMIの埋め込みガイド
- `tei.workspace.yaml` / `semantic/facility.tei`: TEIの型宣言

## 境界

- 実在の施設・規程・権限ではありません。
- R-01〜R-05のdevelopment reviewを追加で受理するものではありません。
- MMI/TEIの入力差の処理だけを確認します。
