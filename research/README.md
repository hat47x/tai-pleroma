# TAI横断研究アジェンダ：証拠に制約された意味の継続性

- 状態: **Proposed / Research plan / NOT RUN**（2026-10-29）
- 提案研究題目: *Evidence-Bounded Semantic Continuity Across Independent Human–AI Systems*
- 対象: TAI / SUI / SEI / TEI / SHO（現行MMI）/ EKI
- 起点: [SCN-001](../scenarios/SCN-001-shared-space-guidance.md) と [TAIの現状](../docs/status.md)
- 最小実験: [SCN-001横断プロトコル](protocols/SCN-001_EPISTEMIC_CONTINUITY.md)

## 1. 目的

独立した製品・人・AIの間で観測、仮説、判断、権限、実行、結果を受け渡す際に、**根拠を欠く意味の確定、旧判断の誤復活、未検証Resultの業務成果への昇格**を防げる条件を調べる。中心に置くのは「製品間を接続できたか」ではなく、利用者が根拠を追い、変化した条件で適切に再判断できるかである。

これは、製品開発を研究のために止めたり、統一Host・共通DB・新たな横断Authority・万能Contractを設ける計画ではない。既存の参照機能、評価fixture、Issue、試験を利用し、実験で不足が確かめられたときだけ元製品のOwnerへ改善候補を渡す。

## 2. 研究課題・仮説と反証

| ID | 検証可能な仮説 | 対照／切り分け | 主な反証・撤回条件 |
| --- | --- | --- | --- |
| H1 / RQ1 | 出典・意味状態・対象版・判断範囲を明示して検査すると、製品境界での不当確定を減らせる | 手動Markdown/Issue、現行参照接続、追加検査あり、検査を除いた版 | 不当確定が減らない／合法な操作の過剰拒否と追加負担が大きい |
| H2 / RQ2 | 受理済み意味を実装から区別すると、継続変更・Target交換時の意味逸脱や再検証漏れを減らせる | 通常のAI支援コーディング、ローコード、TEI | 意味保持に差がない／初期構築・維持費用が改善を相殺 |
| H3 / RQ3 | 判断・権限・委任・結果を独立に検証すると、個々の処理が正常でも全体で不正な行為を減らせる | 委任しない場合、状態コードだけを確認する場合、独立結果検証あり | 不正作用が通過する／実用負担が高い／結果検証が成立しない |
| H4 / RQ4（後続） | 矛盾・未決・少数仮説を残すと、早期収束に伴う判断誤りを減らせる | 通常の要約・単一回答 | 実利用者の判断改善が得られない／認知負荷が上回る |
| H5 / RQ5（後続） | 根拠・対象版・再確認条件を残すと、主体交代後の再開精度が高まる | 会話履歴依存、通常文書のみ | 引継ぎ誤りが減らない／記録負担の増加が大きい |

H1〜H3を第一期の対象とする。H4・H5は追跡項目として定義するが、人的実験・縦断実証の準備が整うまで成立を主張しない。先行研究との差分や新規性は**未確定**。論文の独創性主張は系統的な文献レビューと比較結果を得てから審査する。

## 5. 共通評価原則

- 比較条件: B0=Markdown/Issueと人の確認、B1=現行TAI参照機能、B2=不足が判明した検査を追加した構成、B3=B2から選定した検査を外した構成。B2/B3は**採用案ではなく実験条件**であり、機構が未実装ならNOT RUNとする。
- 同じ入力版・課題・評価基準を使用する。人の習熟度、AIモデルと設定、実行順序・実験者を記録する。公開評価前に保留入力を確定する。
- 独立したGold判定と実装側の判定を区別する。判定者が確保できない意味・業務正当性の試験を機械判定だけで合格にしない。
- false accept / false reject、根拠再構成、費用・介入回数、欠測・blockedを別々に数える。分母が0の場合は0%や100%とせずN/A。
- 比較対象が未準備の場合は対照群を推測して補完せずNOT RUNとする。1回の合成試験で一般的な優越性を主張しない。
- 元のfixture、外部原本、公開gate、各製品の契約を変更した場合はその版と変更理由を別に記録する。

## 6. 実証水準・安全境界

**現状**: [TAI status](../docs/status.md)に合成fixture、ローカルの読み取り専用参照接続、Owner向けpacketなどの記録がある。しかし実在の施設規程と権限者、人間の意味受理、実Workerの完了・独立結果確認、P-06/N-05、実利用者価値は未実証。過去のreceiptの成功は今回の研究の実験結果ではない。

**Gate**: [R-01〜R-07実物再レビュー](../evaluations/SCN-001-real-object-review.md)なしに実物受理・公開・外部作用へ進まない。`development-review-only`は公開権限でない。`queued`・`cancelled`、`artifactBytesVerified`、`validation=ok`、`runDigest`は、それぞれの限定された意味以上を保証しない。

研究は当面合成データと隔離した読み取り専用試験を用いる。非公開原本、個人情報、認証情報、第三者の資料を公開リポジトリへ転載しない。公開リポジトリで保存するのは共有可能なfixtureとサニタイズした結果・参照だけとする。

## 7. 第一期の完了・撤回判断

第一期の成果物は、(a) 反証可能なプロトコル、(b) 少なくとも1種類の同条件比較と要素除去の観測記録、(c) 費用と見逃し・過剰拒否の評価、(d) 導入／不採用を区別した製品改善候補、(e) 論文草案。

結果に根拠がなければ「改善を確認できなかった」と記録し、TAI独自Runtime/DB/契約の新設を正当化しない。論文化の可否・タイトル・投稿先は結果と先行研究レビューを得てから判断する。本書自体は要求・設計の採用、Issueの完了、研究実施、論文成果を意味しない。
