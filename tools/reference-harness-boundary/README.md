# TAI harness boundary reference

ハーネスと製品の境界を、合成の製品とハーネスで確かめる参照実装です。

**実SUI・TEI・SEI・SHO・EKIには接続していません。** 実製品の認可、監査、複数利用者を証明しません。

## 実行

```text
go test ./...
go run . -out receipt.json
```

`passed=true`は、合成の境界の四つの検査が通ったことだけを示します。

## 検査する条件

- 読み取り。ハーネスが製品を読むと、receiptは`readOnly=true`と製品の版、正本のダイジェストを返す。読み取りの前後で、正本のダイジェストは変わらない。
- 書き込みの拒否。ハーネスが製品の正本を書き換えようとすると、製品は`ErrWriteDenied`を返す。正本のダイジェストは変わらない。
- 文脈の受け渡し。ハーネスが課題を渡すと、製品は文脈IDと版を記録する。正本のダイジェストは変わらない。文脈の上限の後は、渡せなかった課題を`deferred=true`として記録する。
- 提供元の遭遇。ハーネスが提供元のIDと版を記録する。製品の正本は変えない。提供元を正本にしない。
- セッションの終了。ハーネスのセッションが終わっても、製品の正本は読める。ハーネスの読み取りは拒否される。

## 境界

- 入力は合成の製品とハーネスであり、実在の製品ではない。
- receiptは`realProductsConnected=false`を常に持つ。
- 実製品の接続は、各製品の既存契約を確認したうえで別の作業とする。
- このツールはTAI固有の状態DBや共通Contractを新設しない。境界の参照実装である。
