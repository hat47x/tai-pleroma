# TAI Pleroma

個人・組織・社会の各水準において、知識・認識・思考・意思形成・創造・実践・学習が充実した全体として機能することを目指すプロジェクトです。

名称の「泰」は易経第11卦・地天泰、「Pleroma」は充足した全体性を表します。

関連基盤: SUI / TEI / SEI / SHO / EKI。TAIは、それらの集合や新たな中央Hostの構築自体ではなく、利用者から見た統一的な知的機能の成立と、その検証に重点を置きます。
