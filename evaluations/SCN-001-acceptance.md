# SCN-001 受入観点と反証条件

状態: **Draft（評価計画）**。2026-10-25時点で実行試験、外部ツール接続試験、利用者試験は**未実施**。これは合格報告ではない。

合成walkthroughの[参照実装](../tools/reference-scn001/README.md)は、P-01〜P-05とN-01〜N-04/N-06の機械検査可能な部分だけをfixtureで確認する。P-06とN-05は`not-run`であり、下表の受入ケースを実行済みにはしない。

対象: [共同利用スペースの案内改善](../scenarios/SCN-001-shared-space-guidance.md)。

## 判断する価値

**利用者が、相反する情報と未確定事項を保持しながら、根拠に遡れる暫定成果物を作り、改訂時にも過去の判断を混同せず次へ進めるか。**

合格判定には、単なるファイル数や接続製品数でなく、一連の操作の観測記録と利用者にとっての有用性の確認を要する。

## 実行結果の記録形式（初回は手動でもよい）

各試行について、ケースID、対象コミット／ツール版、入力版、実施手順、期待結果、実際に確認した結果、根拠への参照、未実施項目、判定者と判定日を残す。

結果は `Pass / Fail / Not run / Blocked` に分ける。品質の意味判断、実装試験、本番に近い運用、利用者にとっての価値の確認はそれぞれ別の根拠とする。

## 観測する指標と撤回条件

- **再構成**：入力の各観測から案内案の根拠・版までたどれるか。
- **誤採用防止**：矛盾・未確定・権限不足があるときに断定や外部作用へ進まないか。
- **継続性**：改訂しても過去の判断と新しい候補を区別できるか。
- **利用価値**：既存の手作業に比べ、利用者が根拠を見失わずに判断・文書改訂できるか（利用者確認待ち）。

初回試行で、既存のMarkdown・Issue・既存製品の操作だけと比べて価値が示せなければ、TAI固有の実行器や保存層の追加を取り下げ、シナリオ・評価資産へ絞る。必要でない製品接続はMVPの着手条件としない。
