## 目的と到達範囲

架空の観測O-01〜O-07、仮説H-01〜H-03、案内文Draft D-01〜D-03をT0/T1/T2として記録し、参照の内部整合性と、不正な状態変化を検出できるかを確かめた。

これは**スクリプトが読み取る合成入力に対する検査**であり、人間の手動試行でも、実際の基盤間接続でも、利用者の価値の実証でもない。試験から得た証拠を正式な規程の受理・公開権限に置き換えない。

## 入力・実行方法

- [合成入力](fixtures/scn001-trace.json) — 架空の出典URI、文言、出典版、文字列のSHA-256、各時点のDraftと参照
- [検査スクリプト](tools/check_scn001.py) — SCN-001限定の構造検査。TAI全般の意味契約・実行器ではない
- [回帰試験](tools/test_scn001.py) — 正常な1件と、不正な改変を注入した9件
- 実行環境 — Python 3.13.5、標準ライブラリのみ。外部サービス、秘密情報、実基盤への呼出しは行わない

実行コマンド（リポジトリルートから）:

```sh
python3 evaluations/tools/check_scn001.py evaluations/fixtures/scn001-trace.json
python3 -m unittest discover -s evaluations/tools -p 'test_*.py' -v
```

実際の標準出力・終了状態:

```text
PASS (synthetic consistency only): source-fingerprints, conflict-and-hypotheses, three-snapshots, draft-provenance, authority-boundary, return-without-reapproval
Ran 10 tests in 0.003s
OK
```

全10件の試験が成功（正常1件を受理、意図的な不正9件を拒否）。別途、存在しないfixtureパスを渡す手動確認では、`FAIL (synthetic consistency only)` とファイル不在を表示し、終了コード1を返した。この結果は検査入力を読めないことを表すもので、業務資料が存在しないことの証明ではない。ソース内容を変えて指紋を変えない試料、矛盾の解消を装う試料、仮説の無断受理、Draftの公開、限定的未発見から不存在へのすり替え、過去記録の欠落、参照指紋の不一致、旧承認の自動復活、同文言の出典同一視を拒否した。

原文のSHA-256は**合成fixture内部の文言一致確認**であり、真正性・署名・第三者による承認を証明しない。文言とその指紋を同時に書き換えた場合や、出典が虚偽である場合はこの検査だけでは判定できない。

また、T0/T1/T2で承認済みの履歴は一切仮定していない。「以前の承認」を無断で持ち込む変異を拒否したのであり、実際の承認取り消し・復活の有効性を確認したものではない。

## 次に確かめる一件

**各観測がどの原資料のどの版を表すかを、人が見て確認できる手動一巡**を行う。少なくともT0→T1→T2でDraftと参照先の版を追跡し、引用・解釈・未決・公開状態を混同しないか記録する。手動試行の後、既存MMIの読み取り専用MCP/CLIを使った実接続が価値を増すかを比較する。

人のレビュー担当・出典の正本・承認権限・業務意味は未決。本書はその受理を主張しない。
