# 変爻の検査記録

状態: 検査記録（2026-11-01）。合成fixtureの参照評価であり、実SUI・SEI・TEI・SHO・EKIの動作ではありません。

本資料は、[09-変爻の分析](09-変爻の分析.md)と[13-設計ノート](13-設計ノート.md)の検査手順を、SCN-001の参照評価で試した記録です。目的は、変爻の前後で何が観測できるかを確かめることです。合否の証明ではありません。

## 1. 方法

TAIの`tools/reference-scn001`は、SCN-001の合成fixtureを読み、P-01からP-07、N-01からN-08のうち機械的に検査できる条件を評価します。`-fixture`で入力JSONを、`-out`でreceiptの保存先を指定できます。

基準のfixture `testdata/scn001.json`を複製し、一つの項目だけを変えた変種を作り、同じ評価を実行しました。五つの変種は、`tools/reference-scn001/transition_test.go`に固定しました。`go test ./... -count=1`で再現できます。

実行環境は、2026-11-01のTAIの作業ツリー、HEAD `bd30340` です。Go 1.27.0を使いました。

## 5. 読み

### 5.1 変種AとBは、井の九三から坎への一部を観測する

井の九三は「井渫不食」、記録はあるが汲まれない状態です。変種AとBは、仮承認の記録が、正しいDraftへ届かない状態を作ります。参照評価は、P-07とN-07で、これを失敗として示しました。

ただし、この検査は、仮承認に固有のものです。P-07は「development-review-onlyの仮承認を、未公開のD-04へ限定する」検査であり、N-07は「仮承認を公開承認やAuthority検証として扱わない」検査です。仮承認以外のDecisionでは、変種DとEが示すように、N-08の対象になるDEC-03とDEC-04のsubjectが検査されます。それでも、N-08の対象外の一般記録は、まだ検査されていません。

つまり、観測できたのは、仮承認のリンクの到達性と同一性、そしてN-08の対象になる判断のsubjectの到達性と同一性です。井渫不食の一般形、つまり後任が任意の判断記録へ到達できるかは、まだ検査になっていません。

### 5.2 変種Cは、同じ内容に戻っても同じ判断ではないことを観測する

変種Cは、廃止済みのDEC-03をacceptedへ戻しました。O-09の本文はO-02と同じであり、内容の一致だけでは復活しないというSEIの中心的な区別を試す変種です。

参照評価は、P-04、N-01、N-08で失敗しました。N-08は「過去に受理された判断は、本文が同じ文言へ戻っても自動復活せず、正当な確認経路(DEC-04)へ戻る」検査です。P-04は「承認権限が未確認の間は公開・外部作用を保留する」検査であり、N-01は同じ文言で出典版が異なることの構造確認です。三つが連動して失敗することは、復活が、公開の保留と、同一文言の別版の扱いに、同時に影響することを示します。

これは、泰の九三「无平不陂、无往不復」と、井の「改邑不改井」の読みに対応します。内容が戻っても、通りの状態は戻らない。判断の有効性は、内容の一致ではなく、確認の経路で決まります。

### 5.3 検査の限界

- 参照評価は、構造の検査であり、意味の受理や権限の真正性を確かめません。
- 変種は、一つの項目だけを変えています。複数の項目が同時に変わる場合の観測は、別の検査が要ります。
- 実SUI・SEI・TEI・SHO・EKIには接続していません。
- P-06とN-05は `not-run` であり、主体規模の比較とEKIの委任は、この検査の対象外です。
- 変種AとBの失敗は、P-07とN-07の二つに限られます。他の検査が同じ変化を見落としている可能性は、別に確かめる必要があります。

## 6. 検査が示すことと、示さないこと

示すこと。

- 仮承認のリンクが切れたとき、または別のDraftを指したときに、参照評価は失敗する。
- 廃止済みの判断を復活させたとき、参照評価は失敗する。
- 同じ文言が戻っても、判断が自動で復活しないことを、N-08が検査している。
- 仮承認以外でも、N-08の対象になる判断のsubjectのリンク切れと取り違えを、N-08が検出する。

示さないこと。

- 一般の判断記録へ、後任が到達できるか。とくに、N-08の対象外の記録。
- 実製品の権限、監査、複数利用者、版の固定。
- SHOとSEIの中心の受け渡し。
- ハーネスと製品の正本の境界。
- 利用者にとっての有用性。

## 7. 次の検査

1. N-08の対象外のDecisionで、Draftやbasisのリンクを変え、どの検査が反応するかを見る。
2. SHOの成果からSEIの判断記録へ、版と範囲を保って到達できるかを試す。現状は接続がないため、まず接続の設計が要る。


- 変種C: `decisions`の`DEC-03.status`を`accepted`にする。
- 変種D: `decisions`の`DEC-04.subject`を`O-99`にする。
- 変種E: `decisions`の`DEC-03.subject`を`O-03`にする。

実行します。

```text
cd tools/reference-scn001
go run . -fixture <変種のJSON> -out <receiptのJSON>
```

receiptの`cases`で、`status`が`pass`以外の項目を確認します。`passed`と終了コードも合わせて見ます。
