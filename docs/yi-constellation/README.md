# YI Constellation 64卦システム分析

状態: 分析草稿（2026-11-01）。Ownerレビュー前であり、要件の受理、設計の採用、実装や効果の確認を示しません。

## この資料群の目的

TAIを中心とする製品シリーズ YI Constellation について、次の三つを進めます。

1. シリーズ全体の要件と、まだ問いになっていない課題の探索領域を見つける。
2. 各製品の価値を、易の卦の象意に照らして言い直し、強める。
3. 計画、要件、設計の記述を厚くし、既存の記述をレビューする。

対象は六つの製品です。TAI（泰）、SUI（萃）、SHO（升、現行のMMIを含む役割）、SEI（井）、TEI（鼎）、EKI（益）。シリーズ外の隣接製品として、CSWとvs-bear-simulatorにも必要に応じて触れます。

## 何をしないか

- 64卦を製品計画にしません。卦の数と製品の数を対応させず、残りの卦を将来の製品や実装計画として扱いません。
- 卦の読みを仕様、受入条件、設計の正本にしません。読みから得た候補は、各製品の要求文書と設計判断を経て初めて採用されます。
- 効果を実証済みとしません。本資料の価値の記述は仮説であり、測定値はまだありません。
- 各製品の正本を置き換えません。各製品の要求、設計、状態の正本は、それぞれのリポジトリにあります。

## 方法

文化的体系を執筆に使う CSW の手つきを、製品シリーズの読解に移します。とくに次の三つを使います。

- 卦を、陰陽の線の操作だけで済ませず、卦辞、彖伝、象伝、説卦伝、序卦伝、雑卦伝の意味と遷移から読む。
- 下卦と上卦を何の関係として読むかを先に置き、その読みを作者側の規約として明示する。
- 原典で確認した意味、作者が名前と価値文に込めた読み、本分析で新しく構成した読みを分ける。

本資料では、次の四つの区別を語の水準で保ちます。

| 区別 | 意味 | 表記 |
| --- | --- | --- |
| 原典で確認 | 周易の本文で確認できる卦名、構造、文言 | 「原典」と書く |
| 作者の決定 | 製品名、象意の採用、価値文 | 「作者の決定」と書く |
| 本分析の読み | 本資料で構成した解釈と仮説 | 「本分析の読み」と書く |
| 要件候補 | 製品要求として提案するが未受理のもの | `RQ-YI-###`、状態は候補 |

## 用語

| 語 | 本資料での意味 |
| --- | --- |
| 卦 | 六本の陰陽の線からなる状態。本資料では、製品とその周囲を読む単位 |
| 爻 | 卦の中の一本の線。下から上へ、初・二・三・四・五・上と呼ぶ |
| 卦辞 | 卦全体に付された短い文 |
| 彖伝 | 卦辞を説く伝 |
| 象伝 | 卦の象と、そこでの振る舞いを説く伝 |
| 説卦伝 | 八卦の性質と象を説く伝 |
| 序卦伝 | 64卦の並びと、卦から卦への移りを説く伝 |
| 雑卦伝 | 64卦を対にして、短い語で対比する伝 |
| 綜卦 | 卦を上下逆にした卦。本資料では、同じ状況を反対側から見た読みとして使う |
| 錯卦 | すべての爻を陰陽反転した卦。本資料では主に使わない |
