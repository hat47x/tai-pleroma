# 変爻で描く現象と製品

状態: 構想（2026-11-02）。文化体系の読みであり、予測、検証、採用の約束ではありません。

## 1. 変化の書としての易

易を、静的な分類の表として読まない。卦は状態、爻はその状態の中の位置、変爻は位置が変わること、之卦は変わった後の状態である。易の中心は、どの状態にも変化の線が入っていることにある。

この資料は、二層の卦を置く。製品の卦と、現実の現象の卦である。二層を、変爻で結ぶ。現象の卦の一つの爻が変わると、之卦が出る。その之卦が製品の卦と重なるとき、製品は、その現象に対する隣の状態として読める。逆に、製品の卦の一つの爻が変わると、現象の卦へ移るとき、製品の変化が現象の変化として読める。

一度に全部の爻を変えない。一つの爻を変え、前後の状態を比べる。これが、易を変化の書として使うときの最小の手続きである。

卦の割当は、作者の決定である。同じ現象に別の卦を当てることもできる。以下は、唯一の対応ではなく、考えるための置き方である。

## 3. モデルとハーネス

生成AIモデルを乾とする。乾は、天行健、君子以自強不息。止まらずに強くなる力である。ハーネスを巽とする。巽は、風、入る、申命行事。扉を開けずに入り、命令を繰り返し伝える。

乾の上に巽を置くと、姤になる。姤は、乾上巽下、風が天の下に入る。卦辞は「女壮、勿用取女」と説く。強い出会いを、そのまま取り込まない。モデルとハーネスの関係は、この遭遇である。

姤の六爻を変えると、六つの結末が出る。

| 爻 | 之卦 | 読み |
| --- | --- | --- |
| 初六 | 乾 | 出会いがモデルへ戻る。ハーネスが消え、モデルが正本を持つ。 |
| 九二 | 遯 | モデルが退く。ハーネスは追わず、距離を保つ。 |
| 九三 | 訟 | 権限が争いになる。境界を書かなければ、訴訟になる。 |
| 九四 | 巽 | ハーネスが媒体になる。モデルは媒体の中に収まる。 |
| 九五 | 鼎 | 出会いが器を作る。モデルの力が、製品の中に固定される。 |
| 上九 | 大過 | 出会いが過ぎる。ハーネスは、超過を止める。 |

望ましいのは、九四の巽である。ハーネスは、モデルの力を消さず、正本も持たず、媒体として入る。九四が動くと、九五の鼎になる。出会いが製品を作る。ただし、九五は製品の側の判断であり、ハーネスが製品を作るのではない。

初六の乾と、上九の大過が、両端の危険である。初六では、ハーネスが消えて、モデルがすべてを持つ。上九では、出会いが大きくなりすぎて、ハーネスが止めなければならなくなる。ハーネスの価値は、機能を足すことではなく、出会いを九四に保つことにある。

既存の要求RQ-YI-025「姤の遭遇」は、この九四と九五の間に置かれている。提供元のIDと版を記録し、提供元を正本にしない。モデルとハーネスの遭遇を、製品の正本へ持ち込まないための線である。

## 4. 資金と時間

資金の注入を、大有とする。大有は、火天大有、豊かさ、所有。時間の経過を、乾の六爻とする。乾の六爻は、龍の六つの位置である。

まず、乾の六爻を変える。

| 爻 | 之卦 | 局面 |
| --- | --- | --- |
| 初九 | 姤 | 潜んだ力が、市場と出会う。 |
| 九二 | 同人 | 仲間ができ、初期の利用者が集まる。 |
| 九三 | 履 | 一日中、慎んで歩む。拡大の前に、足元を確かめる。 |
| 九四 | 小畜 | 小さく蓄える。資金が入り始める。 |
| 九五 | 大有 | 大きく所有する。規模が立ち上がる。 |
| 上九 | 夬 | 亢龍有悔。突き抜けるが、支えを失う。 |

次に、大有の六爻を変える。

| 爻 | 之卦 | 資金の効果 |
| --- | --- | --- |
| 初九 | 鼎 | 器を作る。製品の基盤に資金を入れる。 |
| 九二 | 離 | 見えるようにする。認知と採用に資金を入れる。 |
| 九三 | 睽 | 分かれる。複数の製品、複数のチームに資金が分かれる。 |
| 九四 | 大畜 | 蓄える。能力とデータを蓄積する。 |
| 六五 | 乾 | 強くなる。モデル自体が強くなる。 |
| 上九 | 大壯 | 強引になる。資金が、過剰な拡大を生む。 |

資金は、時間を速める。乾の九四で小さく蓄え、九五で大きく所有する。しかし、資金が九三の履と九二の同人を飛ばすと、上九の夬か、大有の上九の大壯になる。足元を確かめず、仲間を作らずに、突き抜ける。これが、資金注入による急激な進化の危険である。

シリーズの役割は、飛ばされた線を残すことにある。TAIの交は、履の足場を作る。SUIの聚は、同人の仲間を作る。SEIの汲は、小畜の蓄えを、理由の形で残す。製品は、資金が飛ばした線を、別の速さで作り直す。

## 5. 世界の問題群

世界の問題を、六つの卦で置く。坎、困、蹇、否、剝、明夷。それぞれの変爻が、隣の状態を示す。

| 問題 | 変爻の之卦 | モデルができること | モデルだけではできないこと | シリーズの隣の状態 |
| --- | --- | --- | --- | --- |
| 坎 危険 | 節、比、井、困、師、渙 | 危険を説明し、手順を示す | 危険そのものを除く | 節の境界、井の水源、渙の分散 |
| 困 枯渇 | 兌、萃、大過、坎、解、訟 | 選択肢を出す | 資源を供給する | 萃の集め、解の解放 |
| 蹇 阻害 | 既濟、井、比、咸、謙、漸 | 迂回路を示す | 阻害を除く | 井の水源、比の連合、漸の漸進 |
| 否 閉塞 | 无妄、訟、遯、觀、晉、萃 | 閉塞を分析する | 流れを戻す | 觀の観察、晉の前進、萃の集め |
| 剝 浸食 | 頤、蒙、艮、晉、觀、坤 | 浸食を描写する | 浸食を止める | 頤の養い、蒙の教え、艮の停止 |
| 明夷 暗さ | 謙、泰、復、豐、既濟、賁 | 照らす | 透明性を保証する | 謙の控えめ、復の回復、賁の装い |

この表から、二つのことが読める。

第一に、モデルが動かせるのは、知識の線である。蒙を教え、訟を整理し、明夷を照らす。しかし、坎の危険、困の枯渇、蹇の阻害、否の閉塞、剝の浸食は、資源、権限、制度、時間を必要とする。モデルは、これらの線を一人で動かせない。

第二に、シリーズの製品は、問題の卦そのものではなく、隣の之卦として現れる。井は坎と困と蹇の之卦に現れ、萃は困と否の之卦に現れ、節は坎の之卦に現れる。製品は、問題を解くのではなく、問題の隣の状態へ移るための通路を作る。

## 6. 届かない領域

モデルだけでは届かない領域は、次の五つである。

- 坎の危険。安全は、説明ではなく、設備、権限、訓練、制度で作る。
- 困の枯渇。資源は、生成ではなく、配分と供給で作る。
- 蹇の阻害。アクセスは、迂回ではなく、扉を開ける権限で作る。
- 否の閉塞。流れは、分析ではなく、関係の修復で作る。
- 剝の浸食。停止は、描写ではなく、手を止める決定で作る。

シリーズは、これらを解決しない。シリーズが作るのは、隣の状態への通路である。井の水源、萃の集め、節の境界、解の解放、漸の漸進、觀の観察、晉の前進、頤の養い、蒙の教え、艮の停止。これらは、問題そのものではないが、問題の隣へ移るための具体的な状態である。

## 7. シリーズ全体の狙い

シリーズ全体を、未濟とする。未濟は、火水未濟、まだ完成しない。既濟が完成なら、未濟は、完成の手前で止まらない状態である。

未濟の六爻を変えると、六つの次の状態が出る。

| 爻 | 之卦 | 次の状態 |
| --- | --- | --- |
| 初六 | 睽 | 分離を認める。 |
| 九二 | 晉 | 前進する。 |
| 六三 | 鼎 | 器を作る。 |
| 九四 | 蒙 | 学ぶ。 |
| 六五 | 訟 | 争いを整理する。 |
| 上九 | 解 | 解放する。 |

シリーズの狙いは、既濟になることではない。未濟のまま、必要な線を変え続けることである。鼎を作り、蒙を開き、訟を整理し、解へ向かう。完成を約束せず、次の変爻を残す。

これは、シリーズの限界であると同時に、誠実さである。世界の問題は、六つの製品では解けない。解けないことを認めた上で、隣の状態への通路を作る。

## 9. 変爻の読みから出た含意

第一に、資金は時間を速めるが、線を飛ばす。飛ばされた履と同人を、シリーズが別の速さで作る。

第二に、モデルとハーネスの遭遇は、九四の巽で保つ。九五の鼎は、製品の側の判断である。ハーネスが製品を作らない。

第三に、世界の問題は、モデルだけでは解けない。シリーズは、問題の隣の之卦を作る。通路は、解決ではない。

第四に、シリーズ全体は未濟である。完成を約束せず、次の変爻を残す。

第五に、製品の価値は、現象の名前ではなく、作れる之卦で決まる。現象の卦を当てるだけでは、価値は具体化しない。どの爻を変え、どの之卦へ移るかまで書いて、初めて通路になる。
