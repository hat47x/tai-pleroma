# 構造の検算

状態: 検算記録（2026-11-01）。構造の一致を見たものであり、意味の解釈を確かめたものではありません。

本資料は、[01-64卦のシステム地図](01-64卦のシステム地図.md)と[09-変爻の分析](09-変爻の分析.md)の土台を、機械的に検算した記録です。番号、卦名、上下卦、八×八の配置、三十六の変爻、之卦の象の引用、綜卦の対、序卦の連続を確かめました。

## 1. 目的

64卦の表、八×八の配置、三十六の変爻、綜卦と序卦の対は、本分析の土台です。番号、卦名、上下卦のどれか一つがずれると、そこから出る読みもずれます。本資料は、土台の構造を検算し、読みの前提が崩れていないことを確かめます。

## 2. 検算したこと

- 64卦の一覧。番号、卦名、上卦、下卦、位置（製品、影、空白）の64行。
- 八×八の配置。上卦の行と下卦の列の全64セル。
- 三十六の変爻。要約表の六製品×六爻と、各製品の詳細表の之卦。爻の九と六の表記が、卦の陰陽と一致するかも見る。
- 之卦の象の引用。三十六の詳細表の象の列を、[fixture](../../../evaluations/fixtures/yi-64-hexagrams.json)の大象と、句読点を除いて比較する。
- 序卦伝と雑卦伝の引用。[fixture](../../../evaluations/fixtures/yi-appendix-quotes.json)の八つの引用が、資料の本文に含まれるかを見る。
- 綜卦の五対。11と12、41と42、45と46、47と48、49と50。卦を上下逆にした一致。
- 序卦の連続。11から12、41から43、45から50の遷移。

## 5. 検算しないこと

- 卦辞、爻辞、彖伝、象伝の文言の解釈。象の引用は文字列として比較したが、意味は見ていない。序卦伝と雑卦伝の引用も、文字列としての存在だけを見た。
- 象意の要約が、原典に忠実か。
- 製品に卦を割り当てた理由。これは作者の決定であり、構造の一致とは別です。
- 四つの系の読みの妥当性。
- 64卦を製品計画にしないという主張の妥当性。
- 原典のテキストの異同。検算の基準は、スクリプトに埋め込んだ文王卦序の一覧と、fixtureの大象であり、取得した原典の再読ではありません。

## 6. 検算の限界

- 基準の一覧はスクリプトに、大象と序卦・雑卦の引用はfixtureに埋め込んでいます。原典の取得版を変えるときは、両方とも更新する必要があります。
- 表の列の順序は、資料の表記に依存します。資料の列を入れ替えると、検算も直す必要があります。
- 象の比較は、句読点を除いた文字列の包含です。異体字は、取得版の表記に合わせました。表記の揺れをどこまで許すかは、別に決める必要があります。
- 意味の読みは、構造の一致だけでは支えられません。構造の検算は、読みの前提を守る作業であり、読みの正しさの証明ではありません。
