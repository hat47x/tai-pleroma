# 価値の味わい

状態: 自由な価値提案（2026-11-01）。定性的な読みと発想であり、検証、定量化、採用の約束ではありません。

本資料は、[22-価値の共鳴](22-価値の共鳴.md)、[23-交差する価値](23-交差する価値.md)、[24-価値の生剋](24-価値の生剋.md)で読んだ製品の価値を、ラサ論の「状況、表れ、移ろい」の組合せで読み直します。目的は、製品の価値を、機能や徳目から、使う人の経験の味わいへ移すことです。感情名を先に置かず、どんな状況で、何が表れ、どんな移ろいが混じるかを組みます。五大で場と身体を読む続きは、[26-価値の場所](26-価値の場所.md)に置きました。

## 1. ラサ論を、製品の経験へ移す

ラサ論は、感情を名詞で配るのではなく、状況や対象、表現としての表れ、移ろう情動状態の組合せから、味わいが生まれると読みます。持続する情動と、それを支えたり揺らしたりする一時的な状態を分けます。

製品の経験へ移すと、次の五つになります。

1. 状況。その製品が要る場面。誰と、どこで、何が起きているか。
2. 表れ。製品が実際に見せるもの。画面、カード、手紙、音、動き。心理の説明ではなく、目に見える具体。
3. 移ろい。その場面に混じる、ためらい、安堵、疑い、驚き、疲れ。すべてを揃えない。
4. 持続する味わい。場面の底にある、一つの味。感情名は、最後まで伏せる。
5. 味わいの言葉。経験を一文にしたもの。感情名ではなく、状況と表れの関係で書く。

感情名を先に置くと、「安心できるUI」「信頼のデザイン」のような一般論になります。ラサ論の順序では、状況と表れを先に組み、味わいは後から立ち上げます。利用者の実際の感じ方は、設計者の意図とは別です。本資料は、意図した味わいの案であり、利用者の経験を保証しません。

## 2. 七つの経験を読む

### 2.1 TAI 泰：渡った、という安堵

**状況。** 会議で決まったことが、次の部門へ渡らない。渡したはずの決定が、次の会議で「聞いていない」と言われる。担当者は、渡したつもりで、渡っていない。

**表れ。** 通の地図に、交わっていない場所が赤く出る。会議の後に、誰が何を受け取ったかのカードが一枚残る。受け取らなかったことも、カードに書かれる。

**移ろい。** 渡す前のためらい。渡した直後の安堵。相手が受け取らなかったときの、少しの落胆。次の会議までの、忘れ。

**持続する味わい。** 渡った、という安堵。ただし、すべてが渡ったわけではない、という余白つき。

**味わいの言葉。** 「渡った、という安堵。渡らなかったことも、一枚に残る。」

**自由なアイデア。**

1. 渡しの間。送る前に、一拍置く。何を渡し、何を渡さないかを、指で確認する。
2. 受け取りの札。受け取った側が、一枚の札を返す。札には、受け取ったものと、受け取らなかったものが書かれる。
3. 渡らなかった地図。赤い線を、失敗ではなく、次の交わりの候補として示す。

**願いの要件。** 「私は、渡した後に、何が渡って、何が渡らなかったかを、静かに知りたい。」

**響く相手。** 実務者、部門長、会議の参加者。

### 2.2 SUI 萃：消えなかった、という驚き

**状況。** ワークショップで、カードが集まる。声の大きい人の意見が、要約で残る。少数の違和感が、要約の外へ落ちる。参加者は、自分の声が消えたことに、後から気づく。

**表れ。** カードが一枚ずつ、机に置かれる。島が、利用者の言葉で語る。要約の横に、まだ決めない余白がある。

**移ろい。** 置く前の恥ずかしさ。置いた後の、少しの誇り。要約を見たときの、違和感。余白を見たときの、安堵。

**持続する味わい。** 消えなかった、という驚き。声が、要約に負けなかった。

**味わいの言葉。** 「消えなかった、という驚き。要約の横に、私の声がまだある。」

**自由なアイデア。**

1. 静かなカード。要約されないカードを、一枚だけ置ける。置かれたカードは、島の声で読まれる。
2. 余白の椅子。決めないための、空の椅子。誰も座らない椅子が、余白の存在を示す。
3. 少数の棚。少数意見を、棚に飾る。多数決の外に、少数の棚がある。

**願いの要件。** 「私は、自分の声が要約で消えず、そのまま置かれるのを見たい。」

**響く相手。** 個人の参加者、ファシリテーター、少数派。

### 2.3 SHO 升：土台がある、という希望

**状況。** 現場の小さな改善が、なかなか認められない。昇ろうとすると、原本がない、根拠が薄いと言われる。昇りたいのに、土台が空いている。

**表れ。** 積みの階段。一段ごとに、小さな証拠が置かれる。原本の窓が、成果の隣に開く。空邑の警報が、静かな問いとして出る。

**移ろい。** 昇る前の不安。一段上がったときの、小さな誇り。土台が空だと分かったときの、恥ずかしさ。降りる道を見つけたときの、安堵。

**持続する味わい。** 土台がある、という希望。昇ることより、土台が伴うこと。

**味わいの言葉。** 「土台がある、という希望。昇った高さより、足元の一段。」

**自由なアイデア。**

1. 一段の証。昇る前に、一段だけ証拠を置く。置けないなら、昇らない。
2. 原本の窓。成果の横に、原本が小さく開く。窓を閉じると、成果だけが残る。
3. 降りる道。昇りすぎたときに、降りる道を照らす灯。

**願いの要件。** 「私は、小さな一歩が、土台の上にあると感じたい。」

**響く相手。** 現場の改善者、学習者、品質を担う人。SHOは製品の定義がまだ弱いため、この味わいは仮説として扱う。

### 2.4 SEI 井：理由が、まだここにある

**状況。** 前任者が辞めた。後任が、当時の判断を開く。記録はある。しかし、なぜそう決めたかが、見えない。記録は残っているのに、理由が汲めない。

**表れ。** 井戸の暦。いつ、誰が、どの根拠を汲んだかが並ぶ。井戸端の知らせに、新しい水と古い水の区別が貼られる。汲み手の物語が、迷いごと残る。

**移ろい。** 開く前の、少しの怖さ。理由が見えたときの、安堵。前任者の迷いを読んだときの、親しみ。古い水を飲んだときの、ためらい。

**持続する味わい。** 理由が、まだここにある、という安堵。記録の量ではなく、理由の深さ。

**味わいの言葉。** 「理由が、まだここにある。辞めた人の頭に、少し戻れる。」

**自由なアイデア。**

1. 理由の一雫。記録の横に、理由を一雫だけ添える。全文ではなく、一滴。
2. 井戸端の知らせ。新しい水、古い水、濁った水を、味の言葉で示す。
3. 汲み手の物語。後任が、前任の迷いを物語として読む。成功談ではなく、迷いも。

**願いの要件。** 「私は、前任の迷いごと、理由を汲みたい。」

**響く相手。** 後任、監査、法務、組織の記憶を担う人。

### 2.5 TEI 鼎：器が替わっても、こぼれない

**状況。** 道具を替える。新しいシステムへ移る。移行の説明会で、何が残り、何が消えるかが、はっきりしない。参加者は、自分の意味がこぼれるのではないかと、不安になる。

**表れ。** 器の交換。古い器を讃え、新しい器に注ぐ。凝命の証が、静かに置かれる。意味の引越しの箱に、壊れやすいものの緩衝材が入る。

**移ろい。** 古い器への愛着。新しい器への恐れ。注ぐときの緊張。こぼれなかったときの、安堵。新しい器に、古い香りが残ったときの、驚き。

**持続する味わい。** 器が替わっても、こぼれない、という安堵。新しさの興奮ではなく、意味の連続。

**味わいの言葉。** 「器が替わっても、こぼれない。新しい器に、古い香りが残る。」

**自由なアイデア。**

1. 交換の儀。移行の前に、古い器を讃える短い儀式。感謝を、移行の説明に混ぜる。
2. 緩衝材。壊れやすい意味には、緩衝材を付ける。移行の前に、何が壊れやすいかを示す。
3. 香りの記録。新しい器に残った、古い香りを記録する。機能ではなく、香り。

**願いの要件。** 「私は、器を替えるとき、何がこぼれるかを、前もって感じたい。」

**響く相手。** 開発者、移行担当、標準を扱う人。

### 2.6 EKI 益：出したものが、返ってきた

**状況。** 現場の協力者が、余った時間や計算資源を差し出す。しばらくして、それがどこで使われたか分からない。提供したのに、返ってこない。搾取されたのではないか、と思う。

**表れ。** 反哺の環。提供と受益が、環になって戻る。受益の鏡に、受け取ったものが映る。過ちの贈り物が、次の改善への包みになる。

**移ろい。** 差し出す前の、ためらい。使われたと知ったときの、温かさ。返ってきたときの、少しの驚き。返ってこないときの、疑い。

**持続する味わい。** 出したものが、返ってきた、という温かさ。一方的な善行ではなく、環。

**味わいの言葉。** 「出したものが、返ってきた。環の中に、私の場所がある。」

**自由なアイデア。**

1. 返りの便り。提供したものの行き先を、短い便りで知らせる。金額ではなく、物語。
2. 受益の鏡。受益者が、受け取ったものを、自分の言葉で映す。提供者は、鏡を覗く。
3. 過ちの包み。失敗を、次の改善への贈り物として包む。責めるではなく、包む。

**願いの要件。** 「私は、出したものが、どこかで誰かの仕事になっていると感じたい。」

**響く相手。** 現場の協力者、受益者、公共の commons に関わる人。

### 2.7 ハーネス：道具を、忘れられた

**状況。** AIを替える。別のモデル、別のツールへ移る。会話の続きが途切れる。前のAIが覚えていた文脈を、新しいAIは知らない。利用者は、また最初から説明する。

**表れ。** 風の帳が、セッションの終わりに降りる。帳の向こうに、製品の正本がある。申命の手紙に、何を頼んだかが残る。旅の宿に、行き場のないエージェントが泊まる。

**移ろい。** 替える前の、面倒くささ。続きから始められたときの、安堵。媒体が何を知っているか分からないときの、少しの不安。媒体を忘れたときの、静けさ。

**持続する味わい。** 道具を、忘れられた、という静けさ。媒体が前に出ない。

**味わいの言葉。** 「道具を、忘れられた。風は、扉を開けずに入る。」

**自由なアイデア。**

1. 風の帳。セッションの終わりに、帳が降りる。帳の向こうに、正本がある。
2. 申命の手紙。何を頼んだかを、短い手紙に残す。口頭ではなく、書面で。
3. 旅の宿。エージェントが、一時的に泊まる宿。宿は、家ではない。

**願いの要件。** 「私は、AIを替えても、自分の続きが途切れないと感じたい。」

**響く相手。** 個人のAI利用者、エージェントを導入する組織、AIの説明責任を負う人。

## 4. 感情名を伏せた入口

感情名を先に置くと、経験は一般論になります。「安心の設計」「信頼のUI」ではなく、状況と表れで入口を作ります。

- TAIの入口。「渡したのに、届いていない。その一枚を、ここに置く。」
- SUIの入口。「要約の横に、まだ置かれていない声がある。」
- SHOの入口。「昇る前に、足元の一段を置く。」
- SEIの入口。「辞めた人の、迷いごと読む。」
- TEIの入口。「器を替える前に、こぼれるものを知る。」
- EKIの入口。「出したものが、どこへ行ったかを、便りで知る。」
- ハーネスの入口。「AIを替えても、続きから。」

感情名を伏せた入口は、利用者に「これは自分の場面だ」と気づかせます。感情を約束せず、状況を差し出します。

## 5. 移ろいの余白

製品は、一つの感情へ収束させない方が、味わいが深くなります。

- 安堵の後に、少しの疑いを残す。渡ったけれど、渡らなかったものもある。
- 驚きの後に、少しの恥ずかしさを残す。声が残ったけれど、見られた。
- 希望の後に、少しの疲れを残す。昇ったけれど、足が重い。
- 安堵の後に、少しの悲しみを残す。理由は分かったけれど、人はもういない。
- 温かさの後に、少しの疑いを残す。返ってきたけれど、本当に環か。
- 静けさの後に、少しの不安を残す。忘れられたけれど、媒体は何を知っているか。

移ろいを全部揃えるのではなく、その場面に一つか二つを選びます。すべてを揃えると、感情の見本市になります。

## 7. CSWへの還元

### 7.1 うまく働いたこと

- 感情名を先に置かず、状況と表れを先に組んだこと。「安心」「信頼」のような一般論ではなく、渡しの札、静かなカード、井戸端の知らせという具体が出た。
- 移ろいを一つか二つに絞ったこと。安堵だけ、驚きだけにせず、疑いや恥ずかしさを少し混ぜることで、味わいが深くなった。
- 持続する味わいを、最後まで伏せたこと。味わいの言葉が、感情名ではなく、状況の一文になった。

### 7.2 難しかったこと

- 製品の「表れ」は、文章の所作ではなく、画面、カード、音、動きである。ラサ論の「所作」を、UIの具体へ移すのに時間がかかった。
- 利用者の実際の感じ方は、設計者の意図とは別である。味わいの言葉を、利用者の経験の保証にしないよう、何度も書き直した。
- 七つの製品に、同じ五つの移ろいを置くと、パターンになる。製品ごとに、移ろいの数を変えた。

### 7.3 CSWへの提案

「価値の生剋」の後に、短い節「経験の味わい」を足す案です。

1. 状況を読む。誰と、どこで、何が起きているか。
2. 表れを読む。目に見える具体を、心理の説明から分ける。
3. 移ろいを一つか二つ選ぶ。すべてを揃えない。
4. 持続する味わいを、最後まで伏せて読む。
5. 味わいの言葉を、状況と表れの関係で書く。

注意も添えます。感情名を先に置かないこと。利用者の実際の感じ方を保証しないこと。移ろいを全部揃えないこと。味わいを、効果の証明にしないこと。
