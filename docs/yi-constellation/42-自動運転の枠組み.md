# 自動運転の枠組み

状態: 構想（2026-11-02）。自動運転をロボティクスの前段として読む提案であり、予測、安全認証、実装の約束ではありません。

## 1. なぜ自動運転が先か

ロボティクスの直前に来るのは、自動運転の枠組みである。自動運転は、ロボティクスと同じ構造を持つ。認識し、計画し、制御し、安全を保ち、人に引き継ぎ、隊列を管理し、遠隔で監視し、記録を残す。違いは、走る場所が道路であり、規制と安全の枠組みが、すでに整っていることである。

自動運転は、ロボティクスの予行演習である。系列の記録とプロトコルを、いま作って試せる場所である。系列は、自動運転のスタックを作らない。自動運転の周りで、記録と受け渡しの通路を作る。

## 2. 自動運転の構造

自動運転の枠組みは、次の要素を持つ。

- 自動化の段階。SAE J3016のレベル0から5。レベル3は条件付き自動運転、レベル4は特定の条件下での高度自動運転、レベル5は完全自動運転。
- 運行設計領域。ODD。どこで、いつ、どんな条件で動くか。
- 動的運転タスク。DDT。認識、判断、操作。
- フォールバックと最小リスク状態。MRC。自動運転が続けられないとき、安全に止まる。
- 人の引き継ぎ。テイクオーバー要求と、人の応答。
- 安全。ISO 26262の機能安全、ISO 21448のSOTIF、UL 4600の安全ケース、UN R157のALKS。
- 記録。EDR、DSSAD、ディスエンゲージメント報告、インシデント報告、OTAの記録。
- 隊列。遠隔監視、フリート管理、充電、保管。

系列の役割は、これらの記録と受け渡しの層である。制御でも、安全認証でもない。

## 4. 自動運転の記録と、系列の四つの記録

自動運転の記録は、規制と安全の制度に埋め込まれている。EDR、DSSAD、ディスエンゲージメント報告、インシデント報告、OTAの記録。系列は、これらを置き換えない。系列は、これらを参照し、受け渡しと意味の記録を足す。

系列の四つの記録は、自動運転の記録に対応する。

- 出来事の記録は、EDRとDSSADの出来事を参照する。車両ID、自動化レベル、ODD、行為、権限、安全エンベロープ、結果、証拠。
- 受け渡しの記録は、テイクオーバーとディスエンゲージメントの引き継ぎを記録する。要求、応答、MRC、次の行動。
- 判断の記録は、安全ケースとインシデントの説明を参照する。行為、理由、選択肢、権限、前提、安全の制約、証拠。
- 意味の対応は、旧システムから自動運転スタックへの移行を記録する。移行前後の構成、役割、権限、失われるもの、安全ケースの参照。

系列は、規制の記録を所有しない。規制の記録を持つ組織と、認証された制御器の上で、系列は通路を作る。

## 5. 自動運転からロボティクスへ

自動運転の枠組みは、ロボティクスの前段である。同じ記録を、ロボティクスへ広げる。

- 行為者の種類。車両から、ロボットへ。
- ODD。道路から、工場、家庭、屋外、宇宙へ。
- 安全エンベロープ。車両の安全から、ロボットの安全へ。
- 規制。道路交通の規制から、ロボットの規制へ。
- 記録。EDRとDSSADから、ロボットの出来事の記録へ。

自動運転で作った記録の形式を、ロボティクスでそのまま使う。標準が変わったら、アダプターで対応付ける。自動運転は、系列の記録を試す場所であり、ロボティクスは、その記録を広げる場所である。

## 6. 洞察

第一に、自動運転は、ロボティクスの前の履である。虎の尾は道路であり、安全ケースは、その尾を踏む作法である。系列は、安全ケースを作らない。安全ケースの記録を、通路にする。

第二に、自動運転は、鼎の三本脚を試す場所である。モデルは火、ハーネスは風、プログラミングは脚。車両は器であり、安全ケースは器の承認の印である。三本脚が揃わなければ、器はこぼれる。

第三に、自動運転は、既済にしない系列の試験である。車両を最終的な権威にしない。人の引き継ぎと、安全ケースと、記録が、車両を開いておく。系列は、その開きを支える。

第四に、系列の価値は、制御ではなく、通路である。自動運転の制御は、認証された制御器が行う。系列は、引き継ぎ、理由、意味、余力を記録する。

第五に、自動運転の記録は、ロボティクスの記録の雛形である。四つの記録を、自動運転で作り、ロボティクスで広げる。標準を待つのではなく、記録の形式をいま作る。

## 7. 境界

- 本資料は、自動運転をロボティクスの前段として読む構想です。予測、安全認証、実装の約束ではありません。
- 系列は、自動運転のスタックでも、安全制御器でもありません。記録と受け渡しの層です。
- 自動運転の規制、標準、記録の制度は、国や地域で変わります。本資料は、特定の制度に依存しません。
- 車両、ロボット、モデルのベンダーAPIは、変わり得ます。本資料は、特定のAPIに依存しません。
- 定量化、指標、検証は、本資料の対象外です。
