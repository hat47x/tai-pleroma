# 価値の共鳴

状態: 自由な価値提案（2026-11-01）。定性的な読みと発想であり、検証、定量化、採用の約束ではありません。

本資料は、易の卦の象意と、これまでの製品の読みを、ステークホルダーの願いへ重ねます。目的は、機能を増やすことではなく、各製品の価値が、個人、組織、社会のどの願いに響くのかを、言葉として鮮明にすることです。そこから、魅力的な価値観、要望、要件の候補を、自由に発想します。華厳とマンダラを交差させた続きは、[23-交差する価値](23-交差する価値.md)に置きました。

## 1. 共鳴の方法

一つの製品について、次の順に読みます。

1. 卦の映像。卦辞、彖伝、象伝が描く場面を、短い映像として思い浮かべる。
2. 価値語。その製品の中心を一字で表す。
3. 願い。個人、組織、社会が、その製品に何を望むか。「〜したい」の形で書く。
4. 共鳴する言葉。願いと卦の映像を結ぶ、短い一文。
5. 自由なアイデア。製品の形、入口、儀式、言葉、手触りへの発想。
6. 魅力的な要件。願いを、要求の候補として言い直す。

強さの段階は置きません。代わりに、どの願いに響くか、誰に届くかを書きます。読みは主観であり、効果を確かめたものではありません。

## 2. TAI 泰：交

**卦の映像。** 天地が交わり、万物が通う。上は地、下は天。本来なら離れているものが、入れ替わることで交わる。象は「后以財成天地之道、輔相天地之宜、以左右民」と説く。王は、天地の道を整え、その宜しきを輔相する。前に出るのではなく、間に立つ。

**価値語。** 交。

**個人の願い。** 散らばった仕事が、一本の流れになる。どこで止まったかが、自分にも人にも見える。今日やったことが、明日の判断に続く。

**組織の願い。** 部門の間で、決定が落ちない。中央の台帳を買わずに、全体の流れを見る。監査に耐える説明が、人を責めずに残る。

**社会の願い。** 公共の知識が、制度の間を流れる。決定が誰に届かなかったかを、責めずに記録できる。説明責任が、信頼を生む。

**共鳴する言葉。** 「通いは、つなぐことではなく、交わること。」

**自由なアイデア。**

1. 通の地図。課題がどこで止まっているかを、地図のように見せる。赤い線は、接続ではなく、交わっていない場所を表す。
2. 輔相の誓い。製品が「正本を持たない」と宣言する、短い倫理憲章。最初の画面に置く。
3. 交わりの証。会議の後に、誰が何を受け取ったかを、一枚のカードにする。受け取らなかったことも書く。
4. 止まりの祝祭。止まったことを隠さず、ねぎらう短い儀式。止まりは失敗ではなく、交わりの入口として扱う。
5. 通の手紙。週に一度、課題の流れを、物語の手紙として関係者に送る。数字ではなく、出来事と人で書く。

**魅力的な要件の候補。**

- 「私は、自分の課題がどこで止まっているかを、五分で説明できる。」
- 「私たちの組織は、中央の台帳を買わずに、部門をまたぐ流れを見られる。」
- 「社会は、決定が誰に届かなかったかを、人を責めずに記録できる。」

**響く相手。** 個人の実務者、部門長、監査や説明責任を負う人。

## 3. SUI 萃：聚

**卦の映像。** 沢が地の上に集まる。水が低きに集まり、やがて湖になる。彖は「萃、聚也」と説き、「聚以正也」と続ける。集まること自体ではなく、集まり方の正しさが問われる。象は「君子以除戎器、戒不虞」と、集まった後の備えを説く。

**価値語。** 聚。

**個人の願い。** 散らかった声が、消されずに集まる。自分の違和感が、少数派として切り捨てられない。集まったものを見て、まだ決めずにいられる。

**組織の願い。** 会議の集合知が、声の大きい人の意見に潰されない。集めたカードが、決定の圧力で消えない。集め方の正しさを、後から説明できる。

**社会の願い。** 多様な声が、集約で均されない。集まったものが、誰の声かを辿れる。集めない自由も、価値として残る。

**共鳴する言葉。** 「集めることは、決めることではない。」

**自由なアイデア。**

1. 集めの儀。カードを一枚ずつ置く、静かな儀式。集める前に、目的を声に出す。
2. 島の声。集まった島が、利用者の言葉で語る。AIの要約ではなく、元の声を返す。
3. 正しさの余白。まだ決めないための、明示的な余白。余白があることを、画面で示す。
4. 散らばりの美。外れ値や少数意見を、集約の外に飾る。均すのではなく、残す。
5. 集めの地図。何が集まり、何が集まらなかったかを、一枚の地図にする。集まらなかったものに、名前を付ける。

**魅力的な要件の候補。**

- 「私は、自分の散らかった声が、消されずに集まるのを見られる。」
- 「私たちのチームは、集めたものを、まだ決めずに置いておける。」
- 「社会は、集約で消えた声を、後から辿れる。」

**響く相手。** 個人の思考者、ファシリテーター、多様な声を扱う組織、公共の討議に関わる人。

## 4. SHO 升：昇

**卦の映像。** 地の下から木が伸びる。少しずつ、上へ。彖は「柔以時升、巽而順、剛中而應、是以大亨」と説く。急がず、時を得て昇る。象は「君子以順徳、積小以高大」と、小さな積み重ねを説く。

**価値語。** 昇。

**個人の願い。** 小さな成果が、積み上がって見える。今日の一歩が、昨日の一歩とつながる。成果のどこから来たかを、原本まで辿れる。

**組織の願い。** 現場の小さな改善が、組織の能力になる。空っぽの土台の上に、昇らない。昇りの上限を、事故の前に知る。

**社会の願い。** 進歩が、段階を飛ばさない。積み上げの過程が、後から検証できる。急な昇りが、誰かを取り残さない。

**共鳴する言葉。** 「昇りは、積み上げの言い換えである。」

**自由なアイデア。**

1. 積みの階段。小さな証拠を、一段ずつ並べる。段を飛ばすと、色が変わる。
2. 空邑の警報。土台が空なのに昇ろうとすると、静かに知らせる。警報ではなく、問いとして。
3. 昇りの日記。何を、どこから、いつ昇らせたかを、日記のように残す。
4. 原本の窓。成果の隣に、原本の窓を開く。引用ではなく、窓。
5. 冥升の灯。昇りすぎたときに、降りる道を照らす灯。

**魅力的な要件の候補。**

- 「私は、成果のどこから来たかを、原本まで辿れる。」
- 「私たちの組織は、空っぽの土台の上に、昇らない。」
- 「社会は、進歩の過程を、後から検証できる。」

**響く相手。** 個人の学習者、現場の改善者、品質や監査を担う組織。SHOは製品の定義がまだ弱いため、この共鳴は仮説として扱う。

## 5. SEI 井：汲

**卦の映像。** 木の下に水がある。井戸。村が変わっても、井戸は変わらない。卦辞は「改邑不改井、无喪无得、往来井井」と説く。汲む人が代わっても、井戸は尽きない。象は「君子以労民勸相」と、労りと助け合いを説く。

**価値語。** 汲。

**個人の願い。** 前任者の判断を、その理由ごと汲める。自分が辞めても、なぜを失わない。過去の自分が、今の自分の水源になる。

**組織の願い。** 人が辞めても、判断の理由が残る。監査のときに、当時の根拠へ戻れる。同じ議論を、何度も繰り返さない。

**社会の願い。** 制度が、なぜそうなったかを覚えている。失敗から学べる。次の世代が、同じ井戸から汲める。

**共鳴する言葉。** 「井戸は、水をためない。汲まれることで、尽きない。」

**自由なアイデア。**

1. 井戸の暦。いつ、誰が、どの根拠を汲んだかを、暦のように見せる。
2. 汲み手の物語。後任が、前任の判断を物語として読む。要約ではなく、迷いも含めて。
3. 水脈の地図。判断の根拠が、どの水源から来たかを、地図にする。
4. 渫う。古い記録を、定期的に清める儀式。捨てるのではなく、汲み直す。
5. 井戸端の知らせ。井戸のそばに、新しい水と古い水の区別を貼る。鮮度を、味で示す。

**魅力的な要件の候補。**

- 「私は、前任者の判断を、その理由ごと汲める。」
- 「私たちの組織は、人が辞めても、なぜを失わない。」
- 「社会は、制度の失敗から、次の世代が学べる。」

**響く相手。** 後任、監査、法務、制度の記憶を担う組織、未来の世代。

## 6. TEI 鼎：新

**卦の映像。** 木の上に火がある。鼎。食物を煮て、神に供え、賢を養う。彖は「聖人亨以享上帝、而大亨以養聖賢」と説く。象は「君子以正位凝命」と、位置を正し、命を凝らすことを説く。器が新しくなっても、養いは変わらない。

**価値語。** 新。

**個人の願い。** 道具を替えても、自分の意味を失わない。引っ越しても、大切なものが壊れない。新しい器で、同じものを養える。

**組織の願い。** システムを替えても、意味が漂流しない。移行の前に、何が残り、何が消えるかを知る。新しい器に、古い知恵を移せる。

**社会の願い。** 標準が変わっても、意味が続く。制度の引っ越しで、市民が置き去りにされない。新しい技術に、古い合意を移せる。

**共鳴する言葉。** 「新しさは、器の交換であり、意味の断絶ではない。」

**自由なアイデア。**

1. 器の交換。移行を、交換の儀式として描く。古い器を讃え、新しい器に注ぐ。
2. 凝命の証。意味が正しい位置に凝ったことを示す、静かな証。
3. 意味の引越し。意味を、箱に詰めて運ぶ。壊れやすいものには、緩衝材を付ける。
4. 正位の鏡。意味が正しい位置にあるかを映す鏡。位置がずれると、像が歪む。
5. 鼎のレシピ。何を入れ、何を煮て、何を取り出すかを、レシピのように示す。

**魅力的な要件の候補。**

- 「私は、道具を替えても、意味を失わない。」
- 「私たちの組織は、移行の前に、何が残り、何が消えるかを知る。」
- 「社会は、標準が変わっても、市民の合意を置き去りにしない。」

**響く相手。** 開発者、移行を担う組織、標準や制度に関わる人。

## 7. EKI 益：益

**卦の映像。** 風と雷。益。彖は「損上益下、民説無疆」と説く。上を減らし、下を益す。象は「君子以見善則遷、有過則改」と、善を見て移り、過ちを改めることを説く。益は、足すことではなく、回すこと。

**価値語。** 益。

**個人の願い。** 提供したものが、どこで誰に届いたかを見られる。自分の余りが、誰かの仕事になる。搾取されず、感謝される。

**組織の願い。** 余った資源が、必要な仕事へ回る。提供と受益の対応が、後から見える。一方的な取得が、起きにくい。

**社会の願い。** 余りが、下へ流れる。強い者が、弱い者から奪わない。過ちが、贈り物として還元される。

**共鳴する言葉。** 「益は、上から下へ流れる風である。」

**自由なアイデア。**

1. 反哺の環。提供と受益が、環になって戻る。一方向ではない。
2. 受益の鏡。受益者が、受け取ったものを映す鏡。提供者は、それを覗ける。
3. 過ちの贈り物。失敗を、次の改善への贈り物として包む。責任追及ではなく、学習の品。
4. 余りの市。お金ではない、余りの交換所。時間、計算、知識、場所。
5. 下への風。上から下へ吹く風を、画面の動きで表す。恩恵の向きを、身体で感じる。

**魅力的な要件の候補。**

- 「私は、提供したものが、どこで誰に届いたかを見られる。」
- 「私たちの社会は、余りが、必要な場所へ流れる。」
- 「受益者は、受け取ったものを、自分の言葉で映せる。」

**響く相手。** 現場の協力者、資源を持つ組織、公共の commons に関わる人。

## 8. 媒体（ハーネス）：巽

**卦の映像。** 風。木。入る。彖は「重巽以申命」と説く。命令を、繰り返し伝える。象は「君子以申命行事」と、命を申して事を行う。雑卦伝は「兌見而巽伏」と、見えるものと伏せるものを対にする。風は、扉を開けずに入る。

**価値語。** 入。

**個人の願い。** AIを替えても、課題の続きから始められる。自分の文脈を、AIが覚えていて、でも自分の記録を奪わない。媒体が、前に出ない。

**組織の願い。** エージェントが、権限の内側で動く。越権を、事故の前に止める。誰が何をしたかを、後から辿れる。

**社会の願い。** 見えないインフラが、静かに支える。媒体が何をしたかを、後から検証できる。媒体が、正本を握らない。

**共鳴する言葉。** 「風は、扉を開けずに入る。」

**自由なアイデア。**

1. 風の帳。セッションの終わりに、風の帳が降りる。帳の向こうに、製品の正本がある。
2. 見えない神経。媒体の働きを、神経のように可視化する。普段は見えないが、触れると反応する。
3. 止める斧。巽の上九の「喪其資斧」から、止めるための斧を持つ。中継に徹しすぎない。
4. 旅の宿。行き場のないエージェントが、一時的に泊まる宿。宿は、家ではない。
5. 申命の手紙。ハーネスが製品へ渡す命令を、短い手紙として残す。口頭ではなく、書面で。

**魅力的な要件の候補。**

- 「私は、AIを替えても、課題の続きから始められる。」
- 「私たちの組織は、エージェントの越権を、事故の前に止められる。」
- 「社会は、媒体が何をしたかを、後から辿れる。」

**響く相手。** 個人のAI利用者、エージェントを導入する組織、AIの説明責任に関わる人。

## 9. 星座の物語

朝、個人が課題を開く。散らばった声を集め、小さな証拠を積み、昨日の判断を汲む。意味を新しい器へ移し、余りを下へ回す。その間を、風が運ぶ。

順序は一つではない。集めることから始まる日もあれば、汲むことから始まる日もある。大事なのは、どの器官からでも始められ、どの器官へも渡れることだ。

六つの製品は、器官である。TAIは、器官の間を交わらせる。SUIは、声を集める。SHOは、証拠を積む。SEIは、判断を汲ませる。TEIは、意味を新しい器へ移す。EKIは、余りを下へ回す。ハーネスは、器官の間を走る神経と血管である。神経は、前に出ない。血管は、自分の血を作らない。

この星座は、中央に王を置かない。王の代わりに、輔相がいる。輔相は、決めない。決めるのは、現場の人である。

## 11. 魅力を高める五つの演出

第一に、漢字の響きを活かす。輔相、井、鼎、反哺、聚。漢字は、機能名よりも、物語を含む。製品名の横に、一字の価値語を添える。

第二に、機能ではなく、一日の物語から始める。「何ができるか」の前に、「ある日の、ある人の、ある場面」を置く。

第三に、失敗を、移行として描く。否、困、革は、失敗ではない。通じないこと、枯れること、変えることは、次の状態への入口である。

第四に、身体感覚のある手触りを残す。カードを置く、井戸から汲む、器を交換する。抽象的なダッシュボードより、手の動きを思い浮かべる画面。

第五に、余白を価値として描く。決めない、集めない、渡さない時間。何もしないことが、次の交わりの準備になる。

## 12. 価値の緊張と、その魅力的な扱い

- TAIの交と、SEIの汲み。横の流れと、縦の到達。混ぜずに、二つの通として描く。
- SUIの聚と、SHOの昇。集めることと、昇らせること。集めたものを、すぐ昇らせない余白を置く。
- TEIの新と、EKIの益。意味の保存と、余りの再配分。器を替えても、養いは失わないと描く。
- ハーネスの入と、製品の正本。媒体は、前に出ない。風は、扉を開けずに入る。
- SHOの名前と、MMIの機能。名前より、機能を先に描く。SHOが製品になるかは、別の判断である。
