# CSWへの還流

状態: 提案と実施記録（2026-11-01）。CSWの本文へ戻した内容と、戻す前に確かめた境界を記録します。

本分析は、CSWの文化的体系の読み方を、製品シリーズの設計文書へ移しました。移した結果、CSW側へ戻せる手つきが五つ見つかりました。本資料は、その内容と、CSWへ戻した範囲を記録します。

## 1. 本分析がCSWから借りたもの

- 卦辞、彖伝、象伝の本文へ戻り、卦全体の意味と、その中の位置の意味を合わせて読むこと。
- 説卦伝の八卦の性質を動詞として読み、上下卦の組み合わせを二つの働きの関係として読むこと。
- 下卦と上卦を何の関係として読むかを作者が仮に置き、そのことを明示すること。
- 変爻によって別の卦へ移り、中間の卦と到達の卦を読むこと。困から大過を経て井へ至る二経路の作例を参考にした。
- 井の爻辞から、存在、到達、使用を分けること。九三の使われない井、六四の修繕、九五の使用を読み分ける手つきを、そのままSEIの価値の読みに使った。
- 原典で確認した意味、作者が名前に込めた読み、分析者が新しく構成した読みを分けること。

## 2. CSWへ戻せる知見

### K1 単線の変爻を、局面の転換として読む

本分析は、各製品の六つの局面について、線を一本だけ変え、之卦の卦辞と象を読む手順を36回繰り返しました。この手順は、作品の局面転換にも使えます。人物の置かれた局面を一つ選び、その局面の線を変え、之卦の卦辞と象から、次の局面の意味を読む。長編の転換点、短編の結末、場面の連なりを設計するときに使えます。

本分析では、製品群の外側にある生成AIハーネスにも、同じ手順を使いました。ハーネスの上九「巽在牀下、喪其資斧」は、中継に徹しすぎて、手段と権限を失う局面として読みました。六つの製品とは別の対象に、同じ手順を当てられることを示す例です。

CSWの[具体的な技法](../../../cultural-substrate-weaving/skills/cultural-substrate-weaving/references/writing-techniques.md)には、困から井へ至る二経路の作例と、井の爻辞の読み分けがあります。単線の変爻を六つ並べる手順は、まだ本文にありません。追加の候補になります。

### K2 爻位を、導入の局面として読む

本分析は、初を前提、二を初期運用、三を境目、四を露出、五を中心運用、上を極まりとして読みました。これは、爻位の一般的な読み方の一つを、製品の導入と運用に移したものです。作品でも、人物の局面をこの六つに置くと、同じ爻辞から異なる場面を開けます。とくに、三の境目と四の露出は、内から外へ出る転換点として使いやすい位置です。

この読みは、作者が置く規約です。易の伝統が、すべての作品にこの六局面を当てることを定めているわけではありません。CSWの本文へ戻すときも、規約であることを明示する必要があります。

### K3 綜卦を、失敗や反転の読みとして使う

本分析は、泰と否、益と損、萃と升、井と困、鼎と革の五対を、同じ状況を反対側から見た読みとして使いました。とくに、製品の価値が反転する条件を、綜卦の象から読みました。

作品でも、人物や場面の「反対側」を読むときに使えます。成功している場面の綜卦を読み、その場面が反転したときに何が起きるかを、象から読む。悲劇の転換点、長編のどんでん返し、同じ人物の別の局面を書くときに有効です。

CSWの文化体系の手掛かりには、卦と爻の意味を読むこと、変爻によって別の卦へ移ることが書かれています。綜卦を失敗の読みとして使う手つきは、本文でまだ十分に扱われていません。

### K4 存在、到達、使用の区別を、設計文書へ返す

本分析は、井の爻辞から、記録があること、そこへ到達できること、実際に使われることを分けました。この区別は、作品では、知識があること、相手がそれを受け取れること、実際に受け取られることの区別になります。CSWの井の節は、すでにこの三つを扱っています。

本分析で加わったのは、この区別を、製品や制度の設計文書を書くときにも使える、という点です。記録があることと、後任が汲めることと、実際に使われることは、別の要求になります。設計文書を書くときの手つきとして、CSWの井の節に一文を添えられます。

### K5 象意の類似だけでは割当できないという警戒を強める

CSWの[観点と最初の選定](../../../cultural-substrate-weaving/skills/cultural-substrate-weaving/references/framework-selection.md)は、対象を特定の卦へ帰属するには、象意の類似とは別の割当規約が要ると述べています。本分析でも、製品名の卦は作者が先に決めたものであり、機能の分析から卦を選んだものではありません。名前の後に、機能の偏りを卦の象意で説明すると、事後の正当化になります。

この警戒は、CSWの本文で、もう一段強く書けます。卦の読みは、名前を正当化するためではなく、まだ見えていない問いを出すために使う。製品名や作品の題名に卦を採った場合も、名前と読みを分けて扱う。

## 3. CSWへ戻した編集

CSWの作業規則に従い、生成元と生成物を分けず、本文を直接編集しました。実行した編集は、次の二つです。

1. `skills/cultural-substrate-weaving/references/writing-techniques.md`に、節「六爻の変爻を、局面の転換として読む」を追加した。手順、井の九三から坎へ移る作例、注意を書いた。
2. `skills/cultural-substrate-weaving/references/framework-selection.md`の易の行に、変爻を局面の転換として読む技法を追記した。

編集の内容は、[CSWの差分](../../../cultural-substrate-weaving/)で確認できます。CSWの本文は、製品設計の方法論ではなく、執筆のための手つきとして書きました。製品名や製品の役割は、CSWの本文へ持ち込んでいません。

## 4. 還流の境界

- CSWは執筆のためのスキルであり、製品設計の方法論にしません。戻すのは、書くときに使える手つきだけです。
- 卦の読みを、製品名や作品の題名の事後正当化に使いません。
- 変爻の作例は、説明のためのものであり、効果を確認したものではありません。
- 本分析の36の変化を、そのままCSWの作例にしません。CSWへ戻すのは、手順と一つの短い作例です。
- CSWの三つのスキルの構成、配布、検証の仕組みを変えません。

4. 本分析の読みを、CSWの実作で試すか。試す場合、どの原稿とどの場面を使うか。
