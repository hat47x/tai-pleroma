# 価値の読み方

状態: 自由な手引き（2026-11-01）。価値の資料群の読み方を整理したものであり、分析の結論ではありません。

本資料は、[22-価値の共鳴](22-価値の共鳴.md)から[34-価値の宣言](34-価値の宣言.md)までと[36-価値の具体化](36-価値の具体化.md)の十四の資料を、読む人の目的に合わせて案内します。価値の資料は、構造の資料（01から21）の後に置く別の層です。構造が「何を満たすか」を決め、価値が「誰のどの願いに響くか」を書きます。

## 1. 価値の資料の地図

価値の資料は、四つの群に分かれます。

- 価値の読み。22の共鳴、23の交差、24の生剋、25の味わい、26の場所。
- 価値の語り。27の星座の物語、28の星座の門、29のスライド、30の一枚紙。
- 価値の言葉。31の語彙、32の願いの要件、33の候補と願い、34の宣言。
- 価値の具体化。36の具体化。成果物、使う人の行動、変わったと言える条件。

四つの群は、別々の結論ではありません。同じ価値を、読み、語り、言葉にし、具体化する四つの層です。

## 2. 三つの読みの層

### 2.1 関係の層

[24-価値の生剋](24-価値の生剋.md)。価値と価値の間に働く、養う関係と抑える関係を読みます。汲は交を養い、交は汲を抑える。価値が強くなりすぎたときの毒も読みます。しすぎない価値は、ここから出ました。

### 2.2 経験の層

[25-価値の味わい](25-価値の味わい.md)。状況、表れ、移ろいから、使う人の経験を読みます。感情名を先に置かず、渡った安堵、消えなかった驚き、理由がここにある安堵を、場面から立ち上げます。

### 2.3 場所の層

[26-価値の場所](26-価値の場所.md)。五大の場と身体の質から、製品の居場所を読みます。廊下、円卓、階段、井戸、工房、広場、道。身体の動詞は、渡す、置く、上げる、汲む、注ぐ、差し出す、息を吐く。

三つの層は、[27-星座の物語](27-星座の物語.md)で、一人の一日へ織られます。

## 3. 読む人の目的別の道

### 3.1 三十分で全体をつかむ

1. [34-価値の宣言](34-価値の宣言.md)。七つの約束と、七つの約束しないこと。

3. [28-星座の門](28-星座の門.md)。二つの問いと七つの門。

## 4. 構造の資料との関係

構造の資料は、01から21までです。64卦の地図、製品の卦読み、価値モデル、要件候補、計画、レビュー、変爻、高次の視座、新規領域、CSWへの還流、設計ノート、既存要求との照合、ハーネスの卦読み、変爻の検査、概要資料への反映案、G1パケット、構造の検算、対応レビュー、SHOの扱い。

価値の資料は、構造の資料を置き換えません。構造が「何を満たすか」を決め、価値が「誰のどの願いに響くか」を書きます。G1では、両方を一緒に見ます。

## 5. この価値の資料群がしないこと

- 効果を証明しない。定量化しない。指標を作らない。
- 利用者の声を、直接聞いたものとして扱わない。場面と願いは、分析者が構成したもの。
- 製品の優劣を決めない。門は、順位ではない。
- 構造の要求を置き換えない。G1の判断を先取りしない。
- 易の伝統の定義を代表しない。語の定義は、本分析の読み。

## 6. CSWへの還元について

本資料は、価値の資料群の読み方であり、CSWへ戻す新しい書き方の技法は見つけていません。価値の読みの手順は、[23-交差する価値](23-交差する価値.md)、[24-価値の生剋](24-価値の生剋.md)、[25-価値の味わい](25-価値の味わい.md)、[26-価値の場所](26-価値の場所.md)、[27-星座の物語](27-星座の物語.md)で、それぞれCSWへ戻しています。
