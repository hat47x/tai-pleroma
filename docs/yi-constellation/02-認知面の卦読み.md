# 認知面の卦読み

状態: 分析草稿（2026-11-01）。本分析の読みであり、各製品の仕様や受入の根拠ではありません。

対象は、製品群の認知面に置かれる SHO（升）、SUI（萃）、SEI（井）です。各節は、卦の構造と原典、製品の現在の自己定義、象意から見た位置づけ、四つの系での役割、六爻の局面、綜卦が示す失敗、価値の言い直し、未確認の順に進みます。各卦の六爻を一つずつ変えた場合の前後の読みは、[09-変爻の分析](09-変爻の分析.md)で扱います。

## 1. SHO 升（地風升）

### 1.1 卦の構造と原典

升は、下に巽（風、木）、上に坤（地）を置きます。地の中に木が生え、少しずつ上へ伸びる象です。

- 卦辞: 升、元亨。用見大人、勿恤、南征吉。
- 彖伝: 柔以時升、巽而順、剛中而応、是以大亨。
- 象伝: 地中生木、升。君子以順德、積小以高大。
- 雑卦伝: 萃聚、而升不來也。

彖伝は、柔らかいものが時を得て昇り、従順に浸透して中心と応じるので大いに通ると説きます。象伝は、小さいものを積んで高大に至ることを勧めます。雑卦伝は、萃が集まるのに対し、升は戻ってこない、と対比します。

### 1.2 製品の現在の自己定義

MMI（Markdown Matrix Injector）は、Excel、CSV、XML、Wordの表を、元ファイルのままMarkdown文書へ表示するVS Code拡張と命令行ツールです。読み取り専用の参照、出典の報告、原本から外す手順を持ちます。SHOは、このMMIを含む役割の総称として提案されている名前で、2026-11-01時点ではADR-0024が提案中です。製品群の概要資料はSHO Composerを製品1/6として紹介し、MMIを検証用製品と位置づけています。

MMIの価値文書は、原本を写し直すのではなく、原本を残したまま必要な範囲を示すことを価値の中心に置きます。表が変わっても周囲の説明文を自動で書き換えないこと、AIの要約が妥当かを人が確かめることも、明示しています。

### 1.3 象意から見た位置づけ

升の中心は、文書を作ることではなく、原本から成果へ「昇らせる」ことです。象伝の「積小以高大」は、大きな変換を一度に行わず、範囲を区切って少しずつ移すことを勧めます。MMIの範囲指定（ファイル、シート、セル）と、必要な行と列だけを表示する設計は、この読みとよく合います。

雑卦伝の「升不來」は、さらに強い制約を与えます。昇ったものは戻ってこない。文書へ移した表は、原本へ自動で戻りません。だからこそ、昇った成果の側に、どの版の、どの範囲を、いつ移したかの経路を残す必要があります。MMIの出典報告と原本digestの確認は、この「戻らない」性質への備えとして読めます。

序卦伝は「升而不已、必困」と説きます。昇り続けると必ず行き詰まります。SHOの構想は、表に加えて画像や階層構造も扱い、段階的に移すことを目指します。範囲が広がるほど、昇りの上限と停止条件が重要になります。

### 1.4 四つの系での役割

| 系 | 役割 | 注意する境界 |
| --- | --- | --- |
| 個人 | 資料から必要な範囲を自分の成果へ引き上げ、出典を保つ | 原本の更新に追随できない範囲を、成果側で固定しすぎない |
| 組織 | 台帳、規程、設計表を写し直さず、文書へ昇らせる | 昇った成果が正本と誤解されないよう、参照関係を明示する |
| 社会 | 公開資料、統計、規程を、出典をたどれる形で届ける | 公開の範囲と版を、成果の側で説明できるようにする |
| 生成AIエコシステム | AIが表、画像、階層を読み、文書へ移すときの範囲と来歴を示す | AIの要約と原本の内容を混ぜない |

九三の「升虚邑」は、SHOにとって最も具体的な失敗の型です。原本にない内容を、文書の中で作ってしまう。AIが表を読み、要約し、周囲の文章を補うとき、この失敗は起きやすくなります。MMIが周囲の説明文を自動で書き換えない方針は、この失敗への防御として読めます。

### 1.6 綜卦が示す失敗

升の綜卦は萃です。萃も製品なので、升の反対側は「製品のない影」ではありません。升の失敗は、反転ではなく、次の二つになります。

- 聚まって昇らない。SUIが集めた意味が、成果へ移らない。
- 昇りすぎて困に至る。範囲と版の管理が追いつかず、成果が原本から離れる。

一つ目はSUIとの境界の問題であり、二つ目はSHO自身の上限の問題です。序卦伝の「升而不已、必困」は、二つ目を直接に戒めています。

### 1.7 価値の言い直し

現在の価値文は、文書の作成、参照、出典をたどれる成果物です。本分析は、これに升の象意を加えて、次のように言い直します。

> 原本を残したまま、必要な範囲だけを成果へ昇らせ、昇った後も原本へ戻れる経路を、成果の側に残す。

「戻れる」は、データが原本へ書き戻るという意味ではありません。昇った成果から、どの版のどの範囲を移したかをたどって、原本へ行き着けるという意味です。升不来の性質を認めたうえで、経路だけを残します。

価値の測り方の候補は、次の三つです。

- 原本との差分検出率。成果と原本の食い違いを、公開前にどれだけ見つけられたか。
- 出典に戻れる率。成果の任意の箇所から、原本の版と範囲へ到達できたか。
- 空邑率。原本の裏づけがないまま成果へ移された箇所の割合。

いずれも測定値はまだありません。

## 2. SUI 萃（沢地萃）

### 2.1 卦の構造と原典

萃は、下に坤（地）、上に兌（澤）を置きます。澤が地の上に集まる象です。

- 卦辞: 萃、王假有廟、利見大人、亨、利貞。用大牲吉、利有攸往。
- 彖伝: 萃、聚也。順以説、剛中而応、故聚也。観其所聚、而天地万物之情可見矣。
- 象伝: 澤上于地、萃。君子以除戎器、戒不虞。
- 雑卦伝: 萃聚、而升不來也。

彖伝は、従順と喜びによって人と物が集まり、何が集まったかを見れば天地万物の情が分かると説きます。象伝は、集まるときに武器を除き、思いがけない事態に備えることを勧めます。

### 2.2 製品の現在の自己定義

SUI Sensemakingは、人間とAIが未整理の情報から関係、仮説、構造を見いだし、意味が形づくられる過程を保つ基盤です。中核は親和図法とKJ法に着想を得たキャンバスで、カード、島、保留の印、まとめた理由、元のカードへ戻る経路を持ちます。AIは既定で無効であり、有効にしても提案は候補にとどまります。SafeModeは既定で有効です。

### 2.3 象意から見た位置づけ

萃の中心は、集めることそのものではなく、何が集まったかを見て、そこから全体の情を読むことです。彖伝の「観其所聚」は、集積を観察の対象にすることを求めます。SUIのキャンバスは、まさに集まったものを見る場所です。

象伝の「除戎器、戒不虞」は、集まることの危険を説きます。人が集まれば、同調が生まれ、少数が押し流され、思いがけない事故が起きます。SUIがSafeModeを既定にし、未レビューの本文を共有しないこと、孤立したカードや小さな島を数の多さで押し流さないことは、この備えとして読めます。

雑卦伝の「萃聚、而升不來」は、萃の次の状態を指します。集まったものが昇るのが升であり、昇ったものは戻らない。SUIの価値は、集めることで完結せず、集めたものが次へ渡る形を残すことで完成します。ただし、SUI自身が昇りを強制してはいけません。早すぎる収束を避けるというSUIの中心原則は、萃の「まだ決めない」側を守るものです。

### 2.4 四つの系での役割

| 系 | 役割 | 注意する境界 |
| --- | --- | --- |
| 個人 | 違和感や未分化の記憶を、早すぎる結論に畳まずに置く | 個人の内面の記録を、本人の同意なく外へ出さない |
| 組織 | 部署をまたぐ観測を集め、少数意見を数の力で消さない | 集まった場が、事実上の決定の場にすり替わらない |
| 社会 | 異なる経験を持つ参加者の声を集め、合意の前に材料を並べる | 集める手続きの正当性と、参加の自発性を保つ |
| 生成AIエコシステム | モデルが生成した候補を、事実、解釈、仮説の区別を保って集める | 大量生成された候補を、観測の量と取り違えない |

### 2.6 綜卦が示す失敗

萃の綜卦は升です。升も製品なので、萃の失敗は反転ではなく、停滞と逸脱の二つになります。

- 聚まって昇らない。集めた意味が、判断や成果へ渡らない。
- 聚めて党る。集まりが閉じ、外部の観測や反証を受け付けなくなる。

象伝の「除戎器、戒不虞」は、二つ目の失敗への備えです。集まりが強くなると、内側の結束が外側の異論を排除します。SUIの少数保護は、この失敗を防ぐ仕組みとして読めます。

### 2.7 価値の言い直し

現在の価値文は、分からないことを分からないまま扱い、違和感や反証を失わず、形成された意味を後から辿り、組み替え、再評価できることです。本分析は、これに萃の象意を加えて、次のように言い直します。

> 散らばった観測を集め、何が集まったかを観察できる形にし、まだ決めずに、次へ渡せる足場を残す。

「次へ渡せる足場」は、判断を確定するという意味ではありません。集めたものの関係、保留、反証、元のカードへの経路を、次の製品が参照できる形で残すという意味です。SUIの非目標である早すぎる収束は、そのまま保ちます。

価値の測り方の候補は、次の三つです。

- 少数意見の生存率。集約の前後で、少数の見方がどれだけ残ったか。
- 反証の保持数。仮説と合わない材料が、最終案にどれだけ残ったか。
- 元カードへ戻れる率。島や要約から、元の観測へ到達できたか。

いずれも測定値はまだありません。

## 3. SEI 井（水風井）

### 3.1 卦の構造と原典

井は、下に巽（木、風）、上に坎（水）を置きます。木の上に水があり、井戸から水を汲み上げる象です。

- 卦辞: 改邑不改井、无喪无得、往来井井。汔至亦未繘井。羸其瓶、凶。
- 彖伝: 巽乎水而上水、井。井養而不窮也。改邑不改井、乃以剛中也。汔至亦未繘井、未有功也。羸其瓶、是以凶也。
- 象伝: 木上有水、井。君子以勞民勸相。
- 雑卦伝: 井通、而困相遇也。

卦辞は、邑は変わっても井は変わらず、失うことも得ることもなく、人々が往来して汲むと説きます。ただ、井戸にほぼ達しても、まだ縄を下ろしていなければ、功はない。瓶を落とせば凶です。彖伝は、井が養って窮まらないことを中心に置きます。象伝は、労を惜しまず互いに助け合うことを勧めます。

### 3.2 製品の現在の自己定義

SEI Cognitionは、何を観測し、どう解釈し、何を根拠に判断したかを、後から確かめられるようにする製品です。観測、解釈、仮説、推奨、決定、権限、実行意図、実行、業務上の結果を区別して保持します。意味の参照、判断の記憶、能力の観測、認知の方法、意味の交換の五つの約束を持ちます。AIエージェントを動かす実行基盤ではありません。

SEIのブランド文書は、井を「知識を溜める箱」ではなく「地表から直接は触れられない水脈へ、共同体が繰り返しアクセスできる構造」と読みます。卦を仕様の分類表にせず、位置づけを示す象徴層として扱うことも明示しています。

### 3.3 象意から見た位置づけ

井の中心は、水を所有することではなく、汲めることです。卦辞の「汔至亦未繘井」は、完了間近と完了を分けます。井戸のそばまで来たことと、縄を下ろして水を汲んだことは違います。SEIの「分からない」「否定された」「未観測」「未検証」の区別は、この読みと重なります。

爻辞は、井の状態を六段階で示します。

| 爻 | 原文 | 状態 |
| --- | --- | --- |
| 初六 | 井泥不食、旧井无禽 | 泥って飲めない。古井には鳥も来ない |
| 九二 | 井谷射鮒、甕敝漏 | 谷に漏れて小魚を射るだけ。甕が破れて漏れる |
| 九三 | 井渫不食、為我心惻、可用汲 | 清めたのに飲まれない。汲むことはできる |
| 六四 | 井甃、无咎 | 井戸を修める |
| 九五 | 井洌、寒泉食 | 清らかな寒泉が飲まれる |
| 上六 | 井収勿幕、有孚元吉 | 井戸を収めて幕を張るな。開いておく |

九三の「井渫不食」は、SEIにとって最も重要な失敗の型です。記録はある。根拠も揃っている。しかし、誰も汲まない。能力はあるのに使われない状態であり、製品の価値が実現していない状態です。SEIの現在の価値軸は、過去の判断を再構成できるか、意味を分けられるか、改訂の整合性を保てるかを見ますが、「後任が実際に汲めたか」は、まだ独立した観点になっていません。

### 3.4 四つの系での役割

| 系 | 役割 | 注意する境界 |
| --- | --- | --- |
| 個人 | 自分の判断の理由を、後から汲める形で残す | 記録が本人の負担になり、使われなくならないようにする |
| 組織 | 担当者が替わっても、当時の根拠、未決、責任者を汲める | 汲めることと、責任を引き継ぐことを混同しない |
| 社会 | 行政、研究、司法の判断が、担当や技術の交代を越えて検証できる | 社会の意思決定を代行しない |
| 生成AIエコシステム | 提供元が変わっても意味の層が残り、異なる系の間で意味を交換できる | 意味の約束と、バイト列の表し方を混ぜない |

| 爻 | 局面としての読み | 製品への含意 |
| --- | --- | --- |
| 初六 | 放置された井戸 | 使われない記録の検知。存在と使用を分ける |
| 九二 | 狭い用途への漏れ | 部分利用、権限外の参照、蓄えの散逸の検知 |
| 九三 | 清められたが飲まれない | 記録はあるが到達できない状態。汲み上げ経路の検証 |
| 六四 | 井戸を修める | 使われない期間の保全と移行 |
| 九五 | 清らかな泉が飲まれる | 中正な運用。現在の理想状態 |
| 上六 | 幕を張らない | 開示の既定。閉じる理由を明示する |

### 3.6 綜卦が示す失敗

井の綜卦は困です。困は、澤の上に水がない象であり、象伝は「君子以致命遂志」と説きます。井の影は、記録がないことではなく、水が枯れることです。資料の提供元が消える、担当者が去る、費用が尽きる、信頼が失われる。どれも、井戸の中身ではなく、水脈と汲み手の側の枯渇です。

SEIの現在の価値軸に、提供元からの独立と実行手段からの独立があります。これは困への備えとして読めます。ただし、独立は枯渇を防ぐ条件の一つであって、枯渇の検知そのものではありません。何が失われたら判断の再構成ができなくなるかを、あらかじめ観測点として置く必要があります。

### 3.7 価値の言い直し

現在の価値文は、何を観測し、どう解釈し、何を根拠に判断したかを、後から確かめられるようにすることです。本分析は、これに井の象意を加えて、次のように言い直します。

> 判断の根拠を残すだけでなく、後任が実際に汲める井戸にする。汲めない記録は、井戸ではなく泥である。

「汲める」は、検索できるという意味に留まりません。誰が、どの版の、どの根拠へ、どの権限で到達できるかが分かることです。SEIの「能力の定義と実際の状態の観測を分ける」という区別は、そのまま「記録の存在と汲めることの区別」へ延長できます。

価値の測り方の候補は、次の三つです。

- 到達時間。後任が、判断の根拠へ到達するまでにかかる時間。
- 汲まれた回数。記録が、後続の判断や監査で実際に参照された回数。
- 井泥率。更新されず、参照もされない記録の割合。

いずれも測定値はまだありません。参照回数は、価値の代理指標であり、多いことが良いとは限りません。監査のように、一度だけ確実に汲めれば足りる用途もあります。
