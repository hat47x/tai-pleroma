# 交差する価値

状態: 自由な価値提案（2026-11-01）。定性的な読みと発想であり、検証、定量化、採用の約束ではありません。

本資料は、[22-価値の共鳴](22-価値の共鳴.md)で一度読んだ製品の価値を、CSWの「体系の交差」の手順で、別の文化的体系に通します。使うのは、華厳の全体と部分、マンダラの中心と周縁と門です。目的は、製品の価値を、単独の機能から、誰かの仕事の全体と、誰かの中心から読み直し、新しい価値語とアイデアを得ることです。あわせて、この手順から得た知見をCSWへ戻します。

## 1. CSWの交差の手順を、製品の価値へ移す

CSWの「体系の交差と、操作の重ね合わせ」は、二つの使い方を示します。一つは、異なる軸で同じ材料を読むこと。もう一つは、第一の読解が見いだした関係へ、第二の体系を作用させることです。どちらも、第二の体系を、第一の名前へ合わせるための道具にしません。第二の操作が、第一の結果のどこを変えたかを説明します。

本資料では、この手順を、製品の価値へ移します。

1. 第一の読解。易の卦から、製品の価値語と関係を取る。価値語は、交、聚、昇、汲、新、益、入。
2. 第二の体系。全体を変える操作（華厳）と、中心を変える操作（マンダラ）を選ぶ。製品の名前へ、第二の名前を貼らない。
3. 関係へ作用させる。製品の一覧ではなく、第一の読解が見いだした関係へ、第二の操作を当てる。
4. 変化を記録する。第二の操作が、第一の価値語のどこを変えたかを、一文で書く。
5. 新しい問いへ返す。固定した対応ではなく、新しい価値語、門、アイデア、願いの要件として返す。

表を埋めることはしません。六つの製品と、華厳の六相の二十五通りの対応を作ることも、マンダラの八方位へ製品を配置することもしません。第二の体系は、製品を分類するためではなく、価値の読み方を変えるために使います。

## 2. 交差1 易と華厳：製品の価値は、どの全体の中で成立するか

### 2.1 第一の読解

易の読みでは、各製品の価値は、一つの関係として立っています。

- TAIは、目的、根拠、判断、実行、評価を交わらせる。価値語は交。
- SUIは、散らばった観測を集め、何が集まったかを見る。価値語は聚。
- SHOは、原本から必要な範囲を成果へ昇らせる。価値語は昇。
- SEIは、判断の根拠を、後から汲める形で残す。価値語は汲。
- TEIは、知識を正しい位置に置き、新しい実現へ取り出す。価値語は新。
- EKIは、上の余りを下へ回し、過ちを改める。価値語は益。
- ハーネスは、意図、文脈、ツール、権限、観測を中継する。価値語は入。

この読みでは、価値は製品の中にあります。製品が何をするかが、価値の単位です。

### 2.2 華厳の操作

華厳の全体と部分の読みは、同じ一つのものを、異なる全体へ置き直します。工房の一本の道具を、父の所有物として読むか、共同作業の一部として読むか、娘が持ち帰る物として読むかで、道具の意味が変わります。外見を変える前に、誰が使い、何と関係し、何を可能にするかが変わります。

ここでは、製品を「道具」、製品の価値を「その道具が可能にするもの」として読みます。製品を、三つの全体へ置きます。

1. 製品だけの全体。製品の機能と利用者。
2. シリーズの全体。六つの製品と媒体。
3. 誰かの仕事の全体。その人が今日、何を成立させようとしているか。

第二の操作は、製品の名前を華厳の名前に置き換えることではありません。価値の単位を、製品の中から、製品が属する全体の中へ移すことです。

### 2.3 何が変わったか

- TAIの交。製品だけの全体では、交は「見えること」になります。ダッシュボード、進捗、滞留の表示。シリーズの全体では、交は「器官の間の空間」になります。製品と製品の間に、渡し漏れがないかを見る。誰かの仕事の全体では、交は「決定が次の人へ渡ること」になります。見えることではなく、渡ることが価値になります。
- SUIの聚。製品だけの全体では、聚は「集まること」になります。カード、島、クラスタ。シリーズの全体では、聚は「消えないこと」になります。集めた声が、SHOの昇りやSEIの汲みで、消されずに残る。誰かの仕事の全体では、聚は「自分の違和感が、まだ置かれていること」になります。
- SHOの昇。製品だけの全体では、昇は「上へ行くこと」になります。成果、進捗、引用。シリーズの全体では、昇は「土台が伴うこと」になります。原本、版、参照範囲が、昇った先にも残る。誰かの仕事の全体では、昇は「今日の一歩が、昨日とつながること」になります。
- SEIの汲。製品だけの全体では、汲は「記録が残ること」になります。保存、検索、再構成。シリーズの全体では、汲は「他の器官の水源になること」になります。TAIの交やTEIの新が、SEIの水を汲む。誰かの仕事の全体では、汲は「後任が、続きから始められること」になります。残ることではなく、続けられることが価値になります。
- TEIの新。製品だけの全体では、新は「新しくなること」になります。移行、更新、新機能。シリーズの全体では、新は「意味がこぼれないこと」になります。器を替えても、SUIの声、SEIの水、EKIの益がこぼれない。誰かの仕事の全体では、新は「道具を替えても、自分の意味を失わないこと」になります。
- EKIの益。製品だけの全体では、益は「配ること」になります。提供、受益、記録。シリーズの全体では、益は「戻ってくること」になります。提供が、受益の記録として戻り、次の提供の条件になる。誰かの仕事の全体では、益は「出したものが、誰かの仕事になること」になります。
- ハーネスの入。製品だけの全体では、入は「運ぶこと」になります。中継、接続、実行。シリーズの全体では、入は「器官が互いを認識できること」になります。媒体が、製品と製品の間の言葉を運ぶ。誰かの仕事の全体では、入は「忘れられること」になります。利用者が、媒体を意識せずに、成果へ届く。

### 2.4 華厳の六相で問い直す

- 総と別。全体は、誰かの仕事である。部分は、製品、道具、記録、人である。製品を一つ外したとき、同じ全体が成立するか。SEIを外すと、後任の仕事は成立しないが、今日の判断は成立する。全体によって、必要な部分は変わる。
- 同と異。全体を成立させるために、製品の違いがどう働くか。TAIとSEIを同じ「通」に均すと、横の交わりと縦の汲みが消える。違いを消して統一すると、全体は薄くなる。
- 成と壊。全体は、縁によって成立する。製品は、それぞれのあり方を保つ。シリーズは、一つの pipeline ではない。どの製品からでも始められ、どの製品へも渡れる。全体が成立しても、各部分は自分の働きを失わない。

### 2.5 交差から生まれた価値語

| 製品 | 第一の価値語 | 全体の中での価値語 | 変わったこと |
| --- | --- | --- | --- |
| TAI | 交 | 渡る | 見えることから、決定が次へ渡ることへ |
| SUI | 聚 | 消えない | 集まることから、声が消されないことへ |
| SHO | 昇 | 土台が伴う | 上へ行くことから、原本が伴うことへ |
| SEI | 汲 | 続けられる | 残ることから、後任が続きから始められることへ |
| TEI | 新 | こぼれない | 新しくなることから、意味がこぼれないことへ |
| EKI | 益 | 戻ってくる | 配ることから、提供が戻ってくることへ |
| ハーネス | 入 | 忘れられる | 運ぶことから、媒体が意識されないことへ |

### 2.6 自由なアイデア

1. 全体の入口。最初に「あなたは今、どの全体の中にいますか」と聞く。個人の仕事、チームの仕事、組織の仕事、社会の仕事。全体を選ぶと、必要な製品の組み合わせが変わる。
2. 部分の証。各製品が、今どの全体に仕えているかを、静かに示す。製品の画面の隅に、「今日の全体は、後任の引き継ぎです」と書く。
3. 差異の保存。製品の違いを、統合で消さない。TAIの交とSEIの汲みを、同じ「通」の色にしない。違いが見えることを、デザインの原則にする。
4. 壊れない全体。製品を一つ外しても、残りの製品で何が成立するかを示す。全体の脆さを、隠さない。
5. 六相のレビュー。製品のレビューを、総と別、同と異、成と壊の三つの問いで行う。機能の一覧ではなく、全体の中での働きを見る。

## 3. 交差2 易とマンダラ：誰の中心か、どの門から入るか

### 3.1 第一の読解

易の読みでは、各製品は、自分の中心の働きを持っています。TAIは交、SUIは聚、SHOは昇、SEIは汲、TEIは新、EKIは益、ハーネスは入。中心は、製品の中にあります。

### 3.2 マンダラの操作

マンダラの読みは、中心、周縁、門、多重の囲いを置きます。一つの中心が、すべての人にとっての中心ではありません。ある人には作業台が中心で、別の人には戸口が中心です。中心を、他者の位置から読み直します。

ここでは、製品を中心に置きません。ステークホルダーの、今の関心を中心に置きます。製品は、その中心への門、または周縁の支えとして読みます。第二の操作は、製品の機能を中心から外し、誰かの関心を中心へ置くことです。

### 3.3 誰の中心か

- 個人の実務者。中心は、今日の仕事が明日も続くこと。門は、TAIの「今日の課題を一つ入れる」。SEIは、周縁の水源。
- 後任。中心は、前任の判断の理由。門は、SEIの「前任の判断を一つ汲む」。TAIは、周縁の流れ。
- 部門長。中心は、部門の判断が組織の学びになること。門は、TAIの「部門の流れを見る」。SEIは、周縁の証拠。
- 監査。中心は、説明できること。門は、SEIの「根拠を一つ開く」。TEIは、周縁の位置。
- 現場の協力者。中心は、提供したものが搾取されないこと。門は、EKIの「余りを一つ差し出す」。SEIは、周縁の記録。
- 市民。中心は、自分の声が消えないこと。門は、SUIの「違和感を一枚置く」。SEIは、周縁の記憶。
- 開発者。中心は、意味を壊さずに道具を替えること。門は、TEIの「替えたい道具を一つ選ぶ」。SEIは、周縁の水源。
- AIエージェント。中心は、越権せずに役に立つこと。門は、ハーネスの「AIを一つ替える」。製品は、周縁の正本。

### 3.4 何が変わったか

- 製品の中心が、ステークホルダーの中心へ移った。製品は、中心ではなく、門または周縁になった。
- 製品の価値が、機能から、入口の一歩へ変わった。TAIの価値は、ダッシュボードではなく、「今日の課題を一つ入れる」という一歩になった。
- 同じ製品が、人によって中心にも周縁にもなった。SEIは、後任には中心、部門長には周縁、監査には門になる。一つの製品に、一つの中心を固定しない。
- 門は、機能の一覧ではなく、一つの動詞になった。「汲む」「置く」「開く」「差し出す」「替える」。動詞が、入口の手触りを作る。

### 3.5 交差から生まれた門

| 製品 | 門の動詞 | 誰の中心か | 周縁での働き |
| --- | --- | --- | --- |
| TAI | 今日の課題を一つ入れる | 実務者、部門長 | 後任の流れ |
| SUI | 違和感を一枚置く | 市民、個人 | 組織の集合知 |
| SHO | 原本を一つ開く | 監査、学習者 | 成果の土台 |
| SEI | 前任の判断を一つ汲む | 後任、監査 | 組織の記憶 |
| TEI | 替えたい道具を一つ選ぶ | 開発者、移行担当 | 意味の保存 |
| EKI | 余りを一つ差し出す | 協力者、受益者 | 社会の commons |
| ハーネス | AIを一つ替える | 個人、組織 | 見えない神経 |

### 3.6 自由なアイデア

1. 門の一覧。各製品の入口を、機能名ではなく、一つの動詞で示す。製品の一覧の代わりに、門の一覧を置く。
2. 中心の鏡。最初に「今日の中心は何ですか」と聞く。製品は、その中心の周りに、門として並ぶ。
3. 多重の囲い。個人、チーム、組織、社会の四つの輪を置く。同じ製品が、輪によって中心にも周縁にもなる。
4. 他者の中心。同じ製品を、別の人の中心から見る。後任のSEIと、部門長のSEIを、並べて見る。
5. 門番のいない入口。入口に、審査を置かない。一枚のカード、一つの問いから始める。門は、閉じるためではなく、入るためにある。

## 4. 二つの交差が重なるところ

華厳は、価値の単位を「全体」へ移しました。マンダラは、価値の単位を「誰かの中心」へ移しました。二つを重ねると、製品の価値は、次のように言えます。

> 製品の価値は、製品の中にあるのではない。誰かの仕事の全体の中で、その人の中心への門として働くときに、立ち上がる。

この一文は、第一の読解の価値語を否定しません。交、聚、昇、汲、新、益、入は、門の動詞として残ります。ただ、価値の主語が、製品から、誰かの仕事へ移ります。

この重なりから、一つの構想が出ます。星座の門です。最初に「どの全体の中にいますか」と「今日の中心は何ですか」を聞き、その人に合った門を一つだけ示す。製品の一覧を、最初に見せない。門をくぐった後に、製品の全体像を、地図として見せる。

## 5. ステークホルダー別の短い物語

**後任の朝。** 前任者が辞めた。後任は、SEIの門をくぐり、前任の判断を一つ汲む。判断の理由が、迷いごと残っている。TAIの流れは、まだ見ない。今日の中心は、なぜそう決めたのか。SEIは、中心そのものではなく、中心への門である。

**部門長の午後。** 部門の決定が、次の部門へ渡らない。部門長は、TAIの門をくぐり、今日の課題を一つ入れる。流れの地図に、交わっていない場所が赤く出る。SEIの証拠は、周縁で支える。今日の中心は、どこで止まったか。TAIは、中心への門である。

**市民の夕方。** 制度の変更に、自分の声が届かない。市民は、SUIの門をくぐり、違和感を一枚置く。声は、集約で消されずに、島として残る。SEIが、その声の記憶を、周縁で支える。今日の中心は、聞かれたか。SUIは、中心への門である。

## 6. CSWへの還元

### 6.1 うまく働いたこと

- 第二の体系を、製品の一覧ではなく、第一の読解が見いだした関係へ当てたこと。華厳を「製品の分類」に使わず、「価値の単位を全体へ移す操作」に使ったことで、無理な対応が減った。
- 第二の操作が第一の結果をどこで変えたかを、一文で記録したこと。価値語が、名詞から動詞へ変わった。交から渡る、汲から続けられる、入から忘れられる。
- マンダラを、製品の配置図ではなく、ステークホルダーの中心を読む操作に使ったこと。製品が中心から門へ移り、入口の動詞が生まれた。

### 6.2 難しかったこと

- 華厳の六相を、そのまま製品のレビュー項目にすると、一般論の「協力しよう」に戻りやすい。製品の違いを消さない問いとして保つ必要があった。
- マンダラの中心を、製品のロードマップにすると、誰の中心かが消える。中心は、常にステークホルダーの側に置く必要があった。
- 二つの交差を重ねると、説明が長くなる。一つの製品について、全体と中心の両方を読むと、焦点がぼやける。今回は、価値語と門の二つに絞った。

### 6.3 CSWへの提案

「体系の交差」に、価値の読みのための短い手順を足す案です。

1. 第一の読解で、要素の一覧ではなく、関係を一つ取る。
2. 第二の体系から、全体を変える操作か、中心を変える操作を選ぶ。
3. 第二の操作を、関係へ当てる。名前を貼らない。
4. 第一の結果のどこが変わったかを、一文で書く。
5. 新しい価値語、門、問いとして返す。表を埋めない。

あわせて、二つの作例を短く添える案です。易の製品価値へ華厳の全体を当てる例と、マンダラの中心を当てる例です。どちらも、製品の分類ではなく、価値の主語を変える操作として書きます。

注意も添えます。第二の体系を、製品のロードマップや組織図にしないこと。第一の違いを、統一で消さないこと。交差の結果を、効果の証明にしないこと。
