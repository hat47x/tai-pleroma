# 既済にしない系列

状態: 構想（2026-11-02）。文化体系の読みであり、予測、検証、採用の約束ではありません。

## 1. この資料の狙い

前の資料では、製品と現象を変爻で結び、シリーズ全体を未濟と置いた。この資料は、そこから一歩進めて、次の五つを読む。

- 鼎を、モデル、ハーネス、プログラミングの三本脚を完成させる器として読む。
- 乾の終わり、夬、履を、AIの膨張と崩壊、そして慎重な歩みとして読む。
- 明夷が照らす領域と、困と蹇が残す領域を分ける。
- 否と剝を、モデルが促進し得る暗い側面として読む。
- シリーズを、生成AIを既済にしないための系列として読み直す。

## 2. 鼎の三本脚

鼎は、三本脚で器を支える。脚が一本欠ければ、器は傾き、中身がこぼれる。鼎の九四は「鼎折足、覆公餗」と説く。脚が折れ、公の食がこぼれる。器が立派でも、脚が欠ければ、役に立たない。

ここで、三本脚を、モデル、ハーネス、プログラミングと置く。

- モデルは、火。器の中身を煮る力。生成し、変形し、照らす。
- ハーネスは、風。器の周りを巡り、火を調え、煙を逃がす。扉を開けずに入る。
- プログラミングは、脚。器を支え、火から距離を取り、中身を地面に固定する。

モデルとハーネスだけでは、器は空中に浮く。プログラミングが脚となり、器を地面に置く。TEIの鼎は、この三本脚を完成させる構想である。モデルの力を、ハーネスが製品へ渡し、プログラミングが支える。三本が揃って、初めて意味がこぼれない。

鼎の六爻は、三本脚の関係を、六つの局面で示す。

| 爻 | 爻辞の手がかり | 三本脚の読み |
| --- | --- | --- |
| 初六 | 鼎颠趾、利出否 | 脚をひっくり返し、古いものを出す。移行の最初に、古い器を空にする。 |
| 九二 | 鼎有実 | 器に実が入る。モデル、ハーネス、プログラミングが、実のある内容で満たされる。 |
| 九三 | 鼎耳革、其行塞 | 耳が変わり、運べなくなる。接続口、権限、運搬の把手が壊れる。 |
| 九四 | 鼎折足、覆公餗 | 脚が折れ、中身がこぼれる。三本のどれかが欠け、製品が意味を支えられない。 |
| 六五 | 鼎黄耳金鉉 | 黄色の耳、金の鉉。器が正しく担がれる。担ぐのは、利用者か組織。 |
| 上九 | 鼎玉鉉 | 玉の鉉。器が、作法や標準として担がれる。器が、道具以上のものになる。 |

九四の脚が折れるとき、どの脚が欠けるかで、こぼれ方が変わる。

- モデルの脚が欠けると、器は空になる。生成の力がない。
- ハーネスの脚が欠けると、器は熱すぎる。モデルが製品の正本を焼く。
- プログラミングの脚が欠けると、器は傾く。意味はあるが、支えがない。

TEIが三本脚を完成させる、というのは、この三つを一つの器に収めることである。モデルの火を、ハーネスの風で調え、プログラミングの脚で支える。器は、利用者が担ぐ。六五の金鉉と、上九の玉鉉は、器が利用者の手に渡ることを示す。器が、利用者を担ぐのではない。

鼎の象は「君子以正位凝命」と説く。意味を正しい位置に置き、命を凝らす。三本脚は、その正位の条件である。脚が一本でも欠ければ、意味は正しい位置に凝らない。

## 3. 乾の終わり、夬、履

乾の上九は「亢龍有悔」と説く。昇りきった龍は、悔いる。AIの膨張も、同じ形を描く。資金が入り、モデルが強くなり、規模が立ち上がり、やがて、支えを失う。

乾の上九を変えると、夬になる。夬は、決する、突き抜ける。卦辞は「揚于王庭、孚號有厲」と説く。王庭で告げ、信を叫ぶが、危うさがある。上六は「无號、終有凶」と説く。叫ぶ声が止み、終わりに凶がある。AIバブルの崩壊は、夬の上六の静けさに似ている。声が止み、市場が冷え、残ったものだけが残る。

夬は、終わりではない。決することは、余分を断つことである。断った後に、何が残るかが問われる。

乾の九三を変えると、履になる。履は、虎の尾を踏む。卦辞は「履虎尾、不咥人、亨」と説く。虎の尾を踏んでも、噛まれなければ、通る。六三は「眇能視、跛能履、履虎尾、咥人、凶」と説く。片目で見、片足で歩き、虎の尾を踏めば、噛まれる。

AIの産業は、虎の尾を踏んでいる。モデルは強く、リスクは現実にある。履の九三は、乾乾として、夕べに惕る。一日中、慎み、夕べにも恐れる。これが、履の歩みである。

シリーズの姿勢は、夬ではなく、履である。突き抜けるのではなく、虎の尾を踏みながら、噛まれない道を歩く。TAIの交は、履の足場を作る。SUIの聚は、履の仲間を作る。SEIの汲は、履の理由を残す。シリーズは、AIの膨張を止めない。膨張の横に、履の道を作る。

## 4. 明夷が照らす領域、困と蹇が残る領域

明夷は、明るさが地の下に隠れる。卦辞は「利艱貞」と説く。艱難の中に、正しさを保つ。六五は「箕子之明夷、利貞」と説く。箕子は、暗い時代に、明るさを隠して正しさを保った。

生成AIは、人の手が届かなかったIT領域を照らしている。古いシステムの移行、コードの考古学、セキュリティの監査、仕様の再構成。これらは、明夷の領域である。暗い場所に、光を当てる。ただし、光を当てる者は、暗さの論理を理解しなければならない。明夷の六五は、光を隠す。モデルは、古いシステムの前で、自分の光を控えめにし、システムの論理に従う必要がある。

困は、枯渇。卦辞は「有言不信」と説く。言葉はあるが、信じられない。資源は、言葉では作れない。生成AIは、選択肢を出せるが、食料、住居、人手、時間、信頼を作れない。困の領域は、生成AIの生産性向上が届かない、人的、物理的な領域である。介護、建設、保守、物流、交渉、信頼。これらは、現在も費用によってしか賄えない。

蹇は、阻害。卦辞は「利西南、不利東北」と説く。進む方向を選ぶ。生成AIは、迂回路を示せるが、阻害そのものを除けない。蹇の領域は、権限、資格、制度、身体の制約である。扉を開けるのは、モデルではなく、権限を持つ人である。

シリーズは、明夷の光を、古いシステムへ運ぶ。TEIの鼎は、古い器を空にし、新しい器へ意味を移す。SEIの井は、古い判断の理由を汲む。しかし、困と蹇の領域では、シリーズは資源も権限も作れない。作れるのは、井の水源、萃の集め、節の境界、解の解放、漸の漸進という、隣の状態である。

## 5. 否と剝の暗い側面

否は、閉塞。卦辞は「否之匪人、不利君子貞、大往小來」と説く。人の道が通らず、大きなものが去り、小さなものが来る。剝は、浸食。卦辞は「不利有攸往」と説く。進む先がない。上九は「碩果不食」と説く。大きな果実は食べられず、種として残る。

生成AIは、否と剝を促進し得る。情報を溢れさせ、注意を削り、信頼を浸食し、組織の閉塞を深める。モデルは中立ではない。否の閉塞を、モデルが速めることがある。剝の浸食を、モデルが広げることがある。

否の上九は「傾否、先否後喜」と説く。閉塞は、ひっくり返せる。剝の上九は「碩果不食」と説く。最後の果実は、種として残る。シリーズの役割は、この二つを守ることである。閉塞をひっくり返す種、浸食の中で食べられない果実。

これは、接続だけの価値ではない。断る価値である。すべてをつなぐのではなく、つながない。すべてを要約するのではなく、要約しない。すべてを生成するのではなく、生成しない。否と剝の時代には、接続よりも、停止の方が価値を持つことがある。

## 6. 既済にしない系列

既済は、完成。卦辞は「亨小、利貞、初吉終亂」と説く。初めは吉、終わりは乱れる。上六は「濡其首、厲」と説く。頭まで濡れ、危うい。完成は、終わりではない。完成の後に、乱れが来る。

生成AIが既済になる、とは何か。モデルが最終的な権威になり、道具が世界になり、問いが閉じる。完成したAIは、もう変わらない。変わらないものは、腐る。

未濟は、未完成。卦辞は「小狐汔濟、濡其尾、无攸利」と説く。小狐が渡りかけて、尾を濡らす。渡りきれない。しかし、渡る途中である。

シリーズは、生成AIを既済にしないために存在するのかもしれない。完成させない。閉じさせない。問いを残す。シリーズの製品は、それぞれ、ある閉じ方を防ぐ。

| 製品 | 防ぐ閉じ方 | 具体的な機制 |
| --- | --- | --- |
| TAI | 流れの閉じ | 決定が次へ渡らないとき、受け渡しの記録と抜けの一覧で、渡りを開く。 |
| SUI | 声の閉じ | 要約で声が消えるとき、反映の対応表と少数意見の欄で、声を残す。 |
| SHO | 出所の閉じ | 主張に出所がないとき、文ごとの出所と参照範囲の対応表で、原本へ戻す。 |
| SEI | 理由の閉じ | 記録に理由がないとき、判断の記録と参照の記録で、理由を開く。 |
| TEI | 意味の閉じ | 移行で意味がこぼれるとき、意味の対応表と失われるものの一覧で、意味を保つ。 |
| EKI | 余りの閉じ | 提供が返らないとき、返りの記録と偏りの検査で、環を開く。 |
| ハーネス | 媒体の閉じ | モデルが正本を持つとき、読み取り専用と書き込みの拒否で、媒体を開く。 |

七つの製品は、七つの閉じ方を防ぐ。シリーズは、完成したAIではなく、開いたAIを保つ。古い文書からの移行を助け、認識力を高め、知識や力を共有し、人の道具であることを保ち、ドメイン知識を凝集して形とし、理解と協業を助ける。これらは、AIを完成させる仕事ではなく、AIを開いておく仕事である。

## 7. EKIの益の不足と発展余地

EKIは、余りの交換を通して、資源問題のごく一部にアプローチする。しかし、益を充分に体現しているとは言えない。益は、配ることだけではない。彖は「損上益下、民説無疆」と説き、象は「見善則遷、有過則改」と説く。益は、善を見て移り、過ちを改めることまで含む。

益の六爻は、配ることの六つの局面を示す。

| 爻 | 爻辞の手がかり | 読み |
| --- | --- | --- |
| 初九 | 利用為大作 | 益は、大きな仕事のために使う。単なる分配ではなく、大きな営みを支える。 |
| 六二 | 或益之十朋之龜 | 益は、価値ある贈り物として来る。受け取る側は、断れない。市場ではない。 |
| 六三 | 益之用凶事 | 益は、凶事に使う。余りの分配ではなく、危機の支援。 |
| 六四 | 中行、告公從、利用為依遷國 | 益は、移転に使う。構造を変えるための支援。 |
| 九五 | 有孚惠心、勿問元吉 | 益は、信による恵み。量ではなく、信。 |
| 上九 | 莫益之、或擊之 | 益がないとき、誰も益さず、攻撃される。環が止まると、反発が来る。 |

EKIの現在の資源共有は、六二と六三の間にある。価値ある贈り物としての分配、危機の支援。しかし、九五の「有孚惠心」と、六四の「遷國」は、まだ弱い。信による恵みと、構造を変える支援である。

ここに、EKIの発展余地がある。分散基盤を通した資源共有から、分散基盤を通した能力の交換へ。余りの分配から、善を見て移る学習へ。過ちを改める返りの経路へ。分散基盤は、目的ではなく、条件である。その上で、信と学習と構造変化を扱う機能が、益の九五と六四に当たる。

これは、EKIが「益のプロダクト」になるための次の一歩である。資源を配るだけでは、益の上九の「莫益之、或擊之」に近づく。環が止まれば、反発が来る。信と学習を環に入れることで、益は、配ることから、育てることに移る。

## 8. 洞察

第一に、TEIの鼎は、モデル、ハーネス、プログラミングの三本脚を完成させる器である。脚が一本欠ければ、九四の鼎折足になる。三本が揃って、意味がこぼれない。

第二に、乾の終わりは、夬と履を含む。AIの膨張は、亢龍で悔い、夬で決し、履で虎の尾を踏む。シリーズの姿勢は、夬ではなく、履である。突き抜けるのではなく、慎重に歩む。

第三に、明夷は、生成AIが人の手の届かなかったIT領域を照らす。困と蹇は、生産性向上が届かない、人的、物理的な領域を残す。シリーズは、明夷の光を運ぶが、困と蹇の資源と権限は作れない。

第四に、モデルは中立ではない。否と剝を促進し得る。シリーズは、接続だけでなく、停止と拒否を含む。閉塞をひっくり返す種、浸食の中で食べられない果実を守る。

第五に、シリーズは、生成AIを既済にしないために存在する。七つの製品は、七つの閉じ方を防ぐ。完成させず、開いておく。これが、シリーズの最も深い目的である。

第六に、EKIは、資源の分配から、信と学習と構造変化へ進む余地を持つ。益の九五と六四が、その次の一歩である。分散基盤は、条件であり、目的ではない。
